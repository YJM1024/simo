# 司墨前端原型 v3（design-first）

> 这是**设计原型**，不是生产前端。数据为演示数据；生产代码未改动。
> 设计来源：[`archive/design/26-前端原型-v3.md`](../../design/26-前端原型-v3.md)。

## 打开方式

直接双击 `index.html`（或在本机浏览器打开）。页面为自包含 HTML（CSS/JS 已内联），不依赖服务器、字体 CDN 或图标库。

- `index.html` — 对话页：左会话树 / 中消息 + 聚合时间轴 + 交互卡片 + 悬浮任务栈 / 右会话概览 + 任务列表。
- `workbench.html` — 工作台：运行状态、Token 用量、最近活动、快捷入口、系统状态。
- `gallery.html` — 组件画廊：左侧导航，右侧组件与状态（独立页面；右侧区域独立滚动）。

### 演示状态

| URL | 状态 |
|---|---|
| `index.html` | 默认：滚到最新，显示交互卡片、悬浮任务栈、右栏任务 |
| `index.html?top=1` | 滚到顶部：显示"上级会话"分隔线与时间轴上的父会话语义 |
| `index.html?state=empty` | 空态：无后台任务，任务栈隐藏，右栏显示空态文案 |

可交互：卡片选项 / 确认 / 取消（确认后新增一条司墨消息 + Toast）；任务栈展开/收起；右栏任务展开；时间轴横条悬停预览、点击定位；页签切换；移动端抽屉。

## 相对 v2 的关键变化

1. **视觉回到"浅色科技风"**：冷白 `#F7F8FA` + 白面板 + 电光蓝/青点缀 + 1px 冷灰线 + 顶部极淡三色氛围；替换 v2 的暖纸/靛蓝。
2. **布局**：面包屑固定 136px，页签紧贴其后且切页不位移；聊天列左对齐，不再居中；右栏 320 常驻。
3. **时间轴**：按 turn 聚合（一条用户消息 + 其后连续司墨消息），30×14 横条，与消息垂直对齐、随消息滚动；两种角色色；父会话边界用 ↑ 标记对应消息分隔线；悬停缩略预览、点击定位、键盘 ↑/↓/Enter。
4. **右栏**：会话概览 + 任务列表两段，任务只放后台执行任务；空态明确。
5. **任务栈**：消息列底部、Composer 上方；最多 3 条；展开三段步骤（已完成/进行中/未完成）；无任务时整体隐藏。
6. **交互卡片**：显式"取消/确认"，未选不可提交；确认后卡片只读并新增一条确认消息。
7. **组件画廊**：独立页面，左导航 + 右滚动，覆盖 tokens/排版/按钮/输入/页签/徽标/会话树/消息/时间轴/卡片/任务栈/右栏/空态/弹层。

## 已知边界（原型阶段）

- 数据全部为演示数据，未接 `/api/*` 与 `/ws`。
- 时间轴横条只显示当前滚动范围内的 turn；父会话"回溯"只做视觉与滚动定位，未拉取真实上级消息。
- 任务栈为**文档流内**组件（不覆盖消息/输入框）；展开会压缩消息可视区，生产实现可按需要改为浮层锚定。
- 1024 以下自动收起右栏、1100 以下侧栏变抽屉、900 以下隐藏时间轴（与设计文档一致）。
- 不包含深色主题 / 256 主题体系；主题化是后续 token 层工作。
- 组件画廊展示的是静态状态；未覆盖全部 hover/focus 实机截图（见 REVIEW.md）。
