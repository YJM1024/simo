# 司墨使用手册（M41 完成态）

> 面向使用者：只用对话和界面，不需要懂内部实现。
> 可执行文件名为 **`simo.exe`**（司墨；私默/思默为语音误识别，正式名以“司墨”为准）；内部 Go module 仍叫 `simo`，只影响源码路径，不影响使用。
> 品牌图标为**墨滴 + 对话气泡**。
> 管理员配置见 [`admin-guide.md`](admin-guide.md)；版本能力与限制见 [`release-notes-v1.md`](release-notes-v1.md)。

## 1. 它是什么

这是一个**本地运行的司墨**：

- 你只跟**一个司墨**说话；它记得你们之前定下的事；
- 它能一边跟你聊，一边在后台推进你交代的任务；一个需求可以拆成多个任务**自动推进**；
- 它能读文件、改文件、执行命令、生成文档、联网查资料——但高风险动作会先问你；
- 数据默认都在你自己的电脑上（默认在用户目录下的 `.simo` 文件夹）；**使用真实模型时，对话内容会发送给 DeepSeek 服务生成回复**；记忆/任务/文件等数据不由司墨主动上传。

**M41 完成态新增**：消息内联**交互卡片**（`chat.send_card`；agent/action 双路由、幂等、版本、`card.updated`、重启持久、fallbackText 兜底、卡片引导）。M34–M40 的顶部选项卡/右栏任务概览/视觉重构/概览 6 条/32px 时间轴继续可用；M32–M33 的向量召回与视图/团队交互打磨继续可用。默认使用**真实模型**。

## 2. 第一次启动

支持 Windows 10/11（64 位）。

1. 找到 `simo.exe`（通常在程序目录里）。
2. 打开 PowerShell，进入它所在目录：

   ```powershell
   cd <simo.exe 所在目录>
   ```

3. 先配置模型 Key（默认是真实模型，没有 Key 会启动失败；见 [`admin-guide.md`](admin-guide.md)）。
4. 启动：

   ```powershell
   .\simo.exe serve
   ```

5. 看到类似 `listening url=http://127.0.0.1:8787` 后，用浏览器打开：

   **http://127.0.0.1:8787**

6. 关闭：回到 PowerShell 按 `Ctrl+C`。
7. 首次打开会自动显示**首启引导**（对话、任务、记忆/智能体、命令面板四件事）；点「开始对话」关闭，之后可在设置里查看快捷键。

> 如果用的是仓库根目录的 `start.ps1`：它会**优先启动 `simo.exe`、兼容旧版二进制**，不需要手动区分。

> **只想先离线体验？** 启动时加 `-model mock`（回复由本地模拟生成，不联网、不需要 Key）：
> `.\simo.exe serve -model mock`
> 真实模型是默认；离线模式只用于熟悉界面。

## 3. 界面：顶部选项卡 + 三栏

| 位置 | 是什么 | 怎么用 |
|---|---|---|
| **顶部** | 全局视图选项卡 + 面包屑 + 操作区 | 顶部横向切换 **对话 / 工作台 / 任务·定时任务 / 智能体 / 团队 / 记忆**；左侧显示当前路径；右侧是页面级操作（通知/设置等） |
| **左栏** | 会话树 + 搜索/置顶 | 顶部搜索框筛会话；点星标置顶；点会话切换；`+ 子会话` 新开一条线；左栏宽度可拖拽（双击复位） |
| **中间** | 当前会话工作区 | 会话内子标签：**对话 / 轨迹 / 文件**；对话页有消息流、交付物卡片、输入区 |
| **右栏** | 任务 / 概览（可收起） | 默认收起为最右侧细竖条；点「任务/概览」展开，任务角标显示运行数；可 pin 固定、Esc 收起；宽度可拖拽 |

顶栏显示：当前会话面包屑、连接状态、并行任务数、**权限模式与审批策略**、当前主题，以及**通知 / 命令 / 设置**入口。

### 3.1 顶部选项卡与右栏（M37/M38/M40）

- **顶部选项卡**：对话（默认）/ 工作台 / 任务·定时任务 / 智能体 / 团队 / 记忆；键盘 ←/→/Home/End 切换，窄屏横向滚动；
- **页内切换**：工作台/任务/智能体/团队/记忆在**中间主内容区**打开（保留三栏骨架），不是浮窗；关闭回对话；
- **文件不是顶级 tab**：文件在会话内「对话 / 轨迹 / 文件」子标签中；Ctrl+K 的“切到文件”只切子标签；
- **右栏细竖条**：任务/概览标签位于最右边缘；默认收起 48px，展开面板向左延伸；运行中显示数字角标，概览更新显示圆点；
- **固定/恢复**：点右栏的 pin（线性图标）固定后切会话不自动收起；再点/切未固定会话/Esc 收起；
- **宽度**：左右分隔条可拖拽，双击复位；左/右宽度存本地；窄屏（≤1180）右栏变浮层，≤820 单列；
- **视觉规范（M40）**：组件统一（Button/Badge/Tabs/Table/Card 等），可见正文不小于 13px、主文字近黑、线性图标（16/20）、去渐变/glow/玩具感；不涉及操作方式变化。

### 3.2 快捷操作（UI-1）

- **命令面板**：`Ctrl+K`（macOS 为 `⌘K`）打开，输入即可混合搜索**命令与会话**；`↑↓` 选择、`Enter` 执行、`Esc` 关闭。命令包括：新建会话、改权限、暂停当前任务、打开设置、打开用量统计、切换主题、切换顶部视图。
- **斜杠命令**：输入框以 `/` 开头时执行命令而不是发消息：
  - `/archive` 归档当前会话（只读，可恢复）；
  - `/rename <新标题>` 重命名当前会话；
  - `/pause` 暂停当前工作流/任务（等价于发送「停」）；
  - `/model <名称>` 记录模型偏好（**当前仅本地记录，后端切换接口未就绪时不会真正换模型**）。
- **@ 引用**：输入 `@` 后选择**会话或文件**，会插入 `@标签` 到草稿；目前是**纯文本引用**（不建立结构化链接），发送后由司墨按文字理解。
- **消息操作**：鼠标移到消息上可**复制**、**引用/回复**、**重试**；引用会显示被引用片段并可点击跳回原消息；重试会重新发送对应请求；流式回复仍可「撤回」。
- **会话搜索/置顶**：左栏搜索框按标题/摘要/id 过滤；每个会话可点星标置顶，置顶会话排在前面。置顶与搜索偏好保存在**当前浏览器**，换浏览器/清理本地数据会重置。

### 3.3 交付物卡片

- 当前会话顶部显示最近产物（最多 4 个 chip），来自任务产物/生成文件；
- 文本/Markdown/图片可**预览**，所有类型可**下载**；更多的用「文件」选项卡看全量；
- 卡片只读，不提供编辑；修改走对话或工具。

### 3.4 设置中心与首启引导

- 设置入口在顶栏（也可用命令面板「打开设置」）；设置页包含**模型、权限、子任务执行者、主题、数据目录、快捷键**；
- **模型**：可记录偏好；后端模型切换接口未就绪时只保存本地偏好，实际模型仍由后端决定；
- **子任务执行者**：可选「任务智能体 NPC」（默认，按任务拆分执行）或「司墨本人」（上下文更连续）；后端执行者配置接口未就绪时只保存本地偏好并提示，实际以服务端为准；
- **权限/主题**：即时生效；数据目录为只读展示；快捷键可查看；
- **首启引导**：首次打开自动显示一次（对话/任务/记忆·智能体/命令面板），点「开始对话」关闭；之后可在设置查看快捷键。引导状态保存在本地。

### 3.5 用量统计

- 入口：顶栏「用量」或命令面板「打开用量统计」；
- 主视图是**树状表格**：每行一个会话（按会话树缩进，带负责人头像），右侧是该行在同一时间轴上的 **sparkline**；父行含下级会话汇总，可折叠；
- 顶部可切换**指标**（消息数 / token）、**粒度**（天 / 周 / 月）、**范围**（7 天 / 30 天 / 自定义）；
- 后端用量接口不可用时，页面会明确显示**示例数据**（示例 token 为估算）；真实数据就绪后以接口为准。

### 3.6 UI-2 深度视图（前端骨架，后端未就绪部分会降级/暂不可用）

> UI-2 目前是**前端骨架**：页面和交互已接入，但轨迹/计划/模型切换/通知持久化等后端接口多数尚未就绪；页面会明确提示“暂不可用/已降级”，不假装成功。

- **轨迹视图**：会话顶部可切换**对话 / 轨迹**；轨迹按时间显示工具调用、审批、任务、压缩、重试、错误；点消息项可跳回对话，工具项展开工具卡片。若后端轨迹接口未就绪，会用“消息 + 工具调用”降级并在页面说明。
- **工具调用卡片**：命令（命令/输出/超时/截断）、文件读写（路径/diff）、搜索、联网（来源链接）、生成文件（产物预览/下载）、审批、错误；未识别的卡片显示脱敏 JSON。审批动作仍在审批条/任务详情完成。
- **通知中心**：顶栏铃铛 + 未读角标；包含任务完成/需审批/错误三类，可筛选、单条/全部已读、点击跳转。后端通知持久化未就绪时只保留当前页面内存历史（刷新后不保留），页面会说明。
- **计划与待办**：中栏「计划」面板显示步骤、依赖、来源会话和待办；确认/拒绝计划、todo 打勾需要后端动作层支持。接口未就绪时显示只读任务投影，操作会提示“暂不可用”，不会本地改任务状态。
- **模型选择器**：composer 内可选择模型/推理强度；后端模型切换接口未就绪时只记录本地偏好并提示，不会真正切换后端模型。
- 计划模式（先出计划、确认后执行）依赖后端 `plan.*` 动作；未就绪时按钮/入口按不可用处理。

### 3.7 交互卡片（M41）

司墨会在对话消息里给出**可点击的交互卡片**（任务确认、重试、审批提示、数据表等），不需要记命令（实现契约见 [`m41-card-contract.md`](m41-card-contract.md)）：

- **两种按钮语义**：
  - 标注“让司墨处理/继续”的按钮（`route=agent`）：点击会把你的动作作为一条消息发给司墨，由它继续对话/任务；不会直接改业务状态；
  - 标注“直接执行”的按钮（`route=action`）：直接走动作层；写入/执行/高风险动作仍按权限询问或审批（R3+ 必须审批），不会因为卡片而绕开审批；
- **状态**：卡片可显示“可操作/已提交/已禁用/已过期”；提交后按钮会暂时禁用，避免重复点击；过期后只显示兜底文字；
- **幂等/版本**：重复点击不会重复执行；司墨更新卡片内容会生成新版本，旧版本只读；
- **兜底**：渲染失败或旧客户端会显示 `fallbackText`（纯文本摘要 + 操作说明），不会白屏、不会自动执行动作；
- **边界**：卡片没有 HTML/脚本/自定义样式；不能跨会话读取数据；动作失败保留原状态并提示。
- 第一次遇到卡片时，界面会用按钮旁的说明/引导告诉你“这一步会做什么”，不确定时可先用“让司墨处理”路线。

## 4. 连续对话：发消息不会打断后台工作

- **你随时发消息，它随时回**；不需要等它"手头这件事做完"。
- 你发新消息时，**正在后台跑的任务不会停**；它会一边回复你，一边继续推进原来的事。
- 你连发三条不同的事，它会分别回复，并**并行**推进；完成后分别汇报。
- 只有你**明确说"停掉 / 别做 X / 改成 Y / 不是这个意思"**，它才会去改或停对应的任务。
- 普通补充、闲聊、新任务，都**不会**打断已经在跑的任务。

**例子**：

> 你：先把上周会议记录整理成周报。  
> （它开始在后台整理）  
> 你：另外帮我看看明天的日程有没有冲突。  
> 你：把报销单按项目分一下类。  
>
> 预期：三条消息各自有回复；三件事并行推进；周报做完会单独汇报。

## 5. 撤回与纠偏

- 回复**还在一个字一个字往外冒**时，可以点「撤回」，或直接说"停 / 不对 / 改成…"；
- 它会把这条**没说完的回复**撤回（聊天里只显示「已撤回」），按你最新的说法重新回答；
- **已经说完的回复不会被撤回**；说错了直接说"刚才那条改成…"；
- **撤回不影响后台任务**；要停任务请明确说"停掉那个任务"。

只有三类情况它会先问你：**有风险的动作**（改线上/删数据/花钱/影响别人/不可逆）、**真的听不懂**（两种理解会导致完全不同的做法）、**你主动要求**它确认。其他琐碎、可逆、有默认做法的事，它会自己定并说明一句。

## 6. 子会话：把一条线单独拎出来

- 直接说"这件事单独开一个子会话做" / "新建一个需求：…"，或左栏 `+ 子会话`；
- 子会话里只有这条线的内容；父会话的聚合视图能看到子会话消息，消息带会话标签；
- 父会话需要文件时，直接说"去那个子会话把文件拿出来"，它按需取用（**不复制文件**）；
- 子会话不是"另一个司墨"，还是同一个司墨在推进不同的事。

## 7. 任务与工作流：一次需求，多个任务自动推进

当你说一件稍大的事，司墨会先拆成**多个任务**，按依赖关系自动执行；这就是"工作流"。

**你会看到**：

- 右栏「任务」按状态分组：**执行中 / 待开始 / 已完成 / 失败**；同一工作流的任务分组显示，带进度条、完成数、耗时；
- **每个任务完成都会单独汇报**（不是等全部做完才说）：一条汇报消息，包含结论、产物/文件、下一个任务；消息里带任务小卡片，点卡片打开详情；
- 任务失败/阻塞会汇报原因、是否重试、是否需要你介入；
- 工作流结束时另有一条总结（不替代逐条汇报）。

**你可以干预**：

- 说"**停**"或点聊天顶栏的「停」→ 暂停工作流：不再启动新任务，运行中的任务跑完即停；
- 暂停后右栏/详情里可以「恢复」继续；
- 点「取消」终止后续任务（运行中的按取消规则处理，已完成的不回滚）；
- 单个任务可以取消/重试；任务详情里能看到阶段、步骤、依赖、产物、审批。

输入框**始终可用**：暂停/运行中都可以继续发消息。

### 7.1 团队页（V2 只读）

入口：顶部「团队」视图。

- **成员 = 下级会话 + 负责人 agent**；展示成员状态（执行中/排队/暂停/完成）、当前任务/进度、并发上限与排队原因；支持按状态筛选/关键词搜索成员；
- 点「进入该成员会话」可切到成员会话直接聊；返回后仍在自己的会话；
- **模板**：V2 团队模板显示角色清单、通用角色/模板角色、继承来源、基础人格与职责；
- **只读**：没有编辑/创建/换负责人控件；创建团队、暂停、换负责人通过对话完成；V0 没有团队记录属预期，V1/V2 有团队记录。

## 8. 会话工作台：对话 / 轨迹 / 文件 + 右栏概览

会话内顶部子标签：**对话 / 轨迹 / 文件**；概览不在中栏，在右栏「概览」细竖条展开。

### 8.1 文件

- 列出本会话的**任务产物、消息附件、工作区文件**；同一文件只出现一次；
- 名称、类型、大小、时间、来源（哪个任务/哪条消息）；
- 文本/Markdown/图片可**预览**，其它类型可**下载**；
- 只读：文件编辑走对话或让司墨用工具改，不在这里直接改。

### 8.2 消息时间轴

- 消息区左侧有 **32px 宽**的迷你时间轴：每条消息一根加粗刻度（用户/司墨/系统颜色不同）；
- **点击刻度**：直接跳到对应消息并高亮，同时固定预览；再点/点外部/Esc 取消；
- hover 150ms 后显示可交互预览；键盘 Tab 聚焦刻度、Enter 跳转；
- 长会话可折叠时间轴；消息很多时，历史区底部有「加载更早消息」。

### 8.3 右栏概览

- 右栏「概览」展开后是**只读**会话概览：目标、约束、现状、已完成、待办、备注、时间线；
- 内容由**会话目标与任务状态生成**，不是另一套可编辑数据；不展示内部执行字段；
- **上限（M40）**：已完成/待办最多 **6 条**、每条 ≤40 字；时间线最多 **6 条**、每条 ≤50 字；超出显示「另有 N 项」；
- 已完成/待办逐项复选框（线性图标，只读）；时间线为“时间 + 文本”纵轴，每条最多两行；
- 打开先读缓存；点「**更新概览**」才重新生成；想调整内容：跟司墨说，改完再点更新。

## 9. 让司墨生成文件：PDF / Word / Excel / PPT / 图片

直接说，例如：

- "把这份总结导出成 **PDF**"
- "整理成 **Word** 文档"
- "做成 **Excel** 表格，两个 sheet：…"
- "做一页 **PPT**，标题…要点…"
- "生成一张**图片**/插图"

**会发生什么**：

1. 生成文件属于"写盘"动作，会先进入**审批**（见 §12）；允许后生成；
2. 文件落到本会话的**文件**选项卡，可直接预览/下载；
3. 图片通常可直接预览；PDF/Word/Excel/PPT 一般下载后用本机阅读器/Office 打开（V1 不做在线 PDF/Office 预览）。

**依赖**：PDF 需要本机有 Chrome 或 Edge（headless 打印）；Word/Excel/PPT/图片需要可用的 Python 3 及文档库（helper 已随程序内嵌，但 Python 运行时需可用；详见管理员指南）。缺失时会明确告诉你缺什么，不会假装成功。

## 10. 联网：搜索与抓取

直接说：

- "**搜索**一下今天的 AI 新闻，给我三条"
- "**打开**这个链接，总结正文"
- "查一下 X，**给出处**"

**规则**：

- 联网属于外部动作，**默认要审批**（首次/每域名按策略询问）；点「允许一次」或「本会话允许」后才访问；
- 抓取只允许 `http/https`，**不会访问内网/本机地址**（防止被网页诱导访问你的路由器/本机服务）；
- 单次抓取有大小与超时限制；超限会截断并说明；
- 搜索结果/抓取内容会显示**来源链接**（可点击），回答里也会尽量给出出处；
- 搜索用的是公开网页结果，质量受页面结构影响；没有配置第三方搜索 Key。

## 11. 定时任务

入口：左栏底部「**定时任务**」。

适合："每天早上 9 点提醒我今天的日程"、"每周五下午整理本周记录"。

**创建**：

1. 点「新建」，填名称、内容（到点后要做什么）；
2. 选触发方式：**一次 / 间隔 / 每天 / 每周 / cron**；
3. 选时间/时区、目标会话；
4. 保存后可在列表里**启用/停用**、**立即运行**、**编辑**、**删除**。

**运行时**：

- 到点会在目标会话里投递这条内容，按正常对话/任务/工作流流程执行，结果以普通汇报消息出现；
- 如果到点时需要审批但没人处理，会**暂停该定时任务并告诉你**（不会偷偷放行）；
- 关机错过：下次启动只补**最近一次**，不补历史全部；
- 重启后定时任务不丢，下次运行时间会重算。

## 12. 权限与审批：它能不能动手

顶栏有「权限」入口，显示当前**沙盒模式 + 审批策略**。

### 12.1 沙盒模式（能碰哪里）

| 模式 | 含义 |
|---|---|
| **只读** | 只能看，不能写/改/执行 |
| **工作区可写（默认）** | 只能在它的工作区里读写；命令也只能在工作区跑 |
| **完全访问** | 可访问任意路径、任意命令（切换需二次确认，风险很高） |

### 12.2 审批策略（动作前问不问）

| 策略 | 行为 |
|---|---|
| **每次询问** | 写/执行/联网都问 |
| **自动（默认）** | 只读自动通过；写/执行/联网询问 |
| **从不询问** | 不询问；需要审批的动作直接拒绝，不会偷偷执行 |

### 12.3 审批卡片

出现在右栏/任务详情，显示：

- 风险等级（读/写/执行/网络）、工具名、**命令/参数原文**、影响范围（文件/路径/目录）；
- 按钮：**允许一次 / 本会话允许 / 拒绝**；
- 如果这次操作需要比当前更宽的权限（**单次提权**），卡片会显示目标模式与理由，批准后**只对本次调用生效**；不能跨档跳级；
- **它不会自动执行待批准操作**。审批人不在（如页面断开）→ 拒绝。

### 12.4 工具与命令

司墨可用的工具（你不需要记名字，直接说事）：

- 读文件、找文件、搜索内容（自动允许）；
- 写文件、改文件（需要审批；写之前会先读）；
- 执行 PowerShell 命令（exec / pwsh；需要审批；默认超时 120 秒；输出很大时会落盘并给你路径；命令环境不会带上 API Key）；
- 生成文档、联网搜索/抓取（按上面规则审批）。

**你可以这样说**："看看工作区里有哪些文件"、"搜一下代码里的 X"、"运行 `...` 看看输出"、"把 `a.md` 里的某段改成…"、"列出这个目录"。

### 12.5 Python 执行（`run_python`）

可以直接让司墨用 Python 做事，例如：

- "用 Python 读一下这个 CSV，统计每个月的总额"；
- "写个 Python 脚本把这几份文件合并，输出到 workspace"；
- "用 Python 算一下这段数据的均值/画个图"。

**能力与边界**：

- 支持**直接给代码**（由它写成临时脚本执行）或执行 **workspace 内的 `.py` 脚本**；可传参数、设置超时（1–120 秒，默认 120 秒）；
- 工作目录是**会话的 workspace**；输出 stdout/stderr 合并，末尾显示 `[exit code: N]`；
- 输出超过约 64KB 会落盘，聊天里给摘要和文件路径；
- **需要审批**（执行类，风险 R2）；只读沙盒模式下直接拒绝；审批策略"从不询问"时同样拒绝；
- 运行环境是**白名单环境变量**，不继承 API Key；但 Python 代码本身仍可执行任意 Python 能力——**只让它运行你信任的代码**；
- 脚本路径必须在允许的工作区内（越界会被拒绝）；超时会终止进程树；
- 找不到 Python 时明确返回 `python_missing`，不会假装成功（配置见管理员指南 `SIMO_PYTHON`）。

## 14. 记忆页（只读）

入口：顶部「记忆」视图（v0.3 浏览器）；旧右栏入口已随 M37/M38 导航收敛。

- **浏览**：按关键词搜索记忆/实体；按类型过滤：场景、语义、规范、程序、工作；点实体可看关系、关联记忆、时间线；
- **冲突**：disputed 记忆并排显示来源/时间/状态，标注「需裁决」；不会自动裁决，修改通过对话；
- **智能体**：按智能体查看通用记忆（跨智能体只读），每条标注来源会话；
- **金字塔**：L0–L4 可折叠的抽象层视图；只读投影，不直接编辑；
- **召回 R2（M27）**：默认开启 2 跳实体/关系召回 + agentic 多步（规划/召回/评估/改写）；信息不足时会**向你追问**（如"你说的是哪一个？"）；召回本身不直接显示 trace，排障入口仅管理员 `-debug` 本机；
- **向量召回（M32，可选）**：设置 `SIMO_RECALL_VECTOR=1` 后启用本地字符 n-gram TF-IDF 向量，与关键词/图谱结果融合评分；默认关闭；不需要外部向量服务/Key，索引由后端重建。
- **自动巩固（M30）**：默认开启；未处理消息达到阈值（默认 8 条）或定时（默认 300 秒）时，自动把会话内容巩固为记忆候选并写入；可在管理员配置中关闭；巩固不改变原文，冲突仍保留 disputed；
- 全部只读：要改就说"记住…"、"改成…"、"忘掉…"；后端接口未就绪时显示空态说明，不伪造数据。

## 16. 自定义视图（M26 + M28 编辑器）

入口：设置中心「自定义视图」或命令面板「打开自定义视图」；在当前会话打开预览/编辑器。

- **对话生成页面**：在对话里让司墨生成/修改视图（如"把这个会话做成一个任务看板"），不是手写页面；
- **13 类块**：chat / form / ask / action / deliverable / text / markdown / table / image / progress / timeline / dag / kanban；数据绑定只读，动作统一走动作层；
- **受控编辑器（M28）**：预览页点「编辑」进入；只能通过结构化控件改标题、块的 props/actions、增删块；保存翻译成白名单 patch（`ui.set_view mode=patch`，带 baseVersion），**不能写任意 JSON**；保存成功生成新版本，失败会定位到字段/块，不产生版本；
- **交互打磨（M33）**：表单提交前校验必填/数字/日期/选项；表格列可排序、分页（仅展示状态，不写库）；看板移动失败**保留原列**、不伪装成功；编辑器支持块搜索、删除块二次确认、有未保存修改时离开/回滚会提示；
- **复杂交互 v2（M34）**：多步表单向导（逐步校验、最后总校验、定位错误步）；表格多列排序/行内编辑/行详情/批量动作；看板 WIP 上限、泳道、卡片排序（本地保存）；新增 `chart` 图表块；表格行可设 `$row` 联动其他块；失败均保留原状态并提示；
- **版本与回滚**：版本不可变；版本面板可预览历史/回滚，回滚生成新版本（不删除历史）；删除是软删；
- **只读预览**：当前会话没有视图时显示空态；未知块/绑定失败/校验失败会降级为表格/说明，不白屏；
- **边界（M26/M28）**：
  - 视图是**同一套会话消息 + 动作的投影**，不是第二数据源；
  - 只支持会话级视图，不支持全局视图；不支持用户手写 schema/任意 HTML/JS/组件树；
  - 生成/修改/回滚通过对话/动作层或受控编辑器；编辑器只做白名单字段；
  - 动作仍受权限/审批约束，R3+ 动作由后端审批；组件级/复杂交互仍是骨架。

## 17. 便携包安装/升级/备份恢复（M29）

完整命令与校验细节见 [`deploy/INSTALL.md`](../deploy/INSTALL.md)；本机二进制用户可按下面理解：

- **便携包**：`deploy/package.ps1` 构建 web + `simo.exe` → zip（含 `start.ps1`、示例配置、manifest、SHA256）；
- **首次安装**：`deploy/install.ps1` 校验包 → 解压到 `%LOCALAPPDATA%\Simo\app` → 初始化数据目录 → 生成 `start.cmd`；
- **升级/回滚**：`deploy/upgrade.ps1` 校验 → 停服 → 自动备份 → 安装 → 健康冒烟；失败自动回滚，`-Rollback` 手动回滚；
- **备份**：`deploy/backup.ps1` 一致性热备（Python `sqlite3.backup`；无 Python 时要求停服复制 db+WAL）→ zip + sha256 + manifest；
- **恢复**：`deploy/restore.ps1` 校验 zip/manifest/`PRAGMA integrity_check` → 先做 pre-restore 备份 → 移动旧 db → 恢复；默认不覆盖 `config.local.json`（含密钥），需要时加 `-RestoreConfig`；
- **实测边界**：便携包构建/restore 已验证；`install.ps1` 首次安装、`upgrade.ps1` 升级/自动回滚/`-Rollback` 及 Docker 构建仍**未完整实测**，以 INSTALL 记录为准；
- **最终便携包（M41）**：`deploy/dist/simo-M41-win-x64.zip`；**SHA256 `6b62bf3c2a52baf97fd51017dc0e07e212ca5b5d2219ce26b66af45c421b9753`（≈11.61 MB；包内 exe `4905F6C7C932021EF5EC548C0D14093795617E3BEF6ADE4373412EB8C2D89421`）**；最终构建 `backend/simo.exe` 2026-11-09 00:20:56（22,002,688 B），前端 app.js 675,939 B。

## 19. 常见问题

| 现象 | 怎么办 |
|---|---|
| 启动就退出，提示需要 API Key | 默认是真实模型；配置 Key 或先用 `-model mock` 离线体验 |
| 页面打不开 `127.0.0.1:8787` | 确认 PowerShell 窗口还在运行；端口可能被占用，换端口见管理员指南 |
| 发消息后它说"在做别的" | 正常并行；它会先回你，再继续后台任务 |
| 想停掉某件事 | 明确说"停掉刚才那个任务"；只说"停"通常指暂停工作流/停止当前回复 |
| 任务一直"待批准" | 点开审批卡片，允许/拒绝；不会自动执行 |
| 生成 PDF/Office 失败 | 可能缺 Chrome/Edge 或 Python 文档库；按提示配置，见管理员指南 |
| 搜索/抓取失败 | 检查网络与审批；内部地址会被拒绝；换公开链接试试 |
| 定时任务没触发 | 检查是否启用、时间/时区、目标会话；需要审批但无人处理会暂停并提示 |
| 概览不更新 | 概览是缓存；点「更新概览」才会重新生成 |
| 想看历史消息 | 用消息区左侧迷你时间轴跳转；底部「加载更早消息」 |
| `@` 选了会话/文件但对方没按引用处理 | @ 目前是**纯文本引用**，不是结构化链接；可在消息里补充说明 |
| `/model` 切了没变化 | `/model` 目前只记录本地偏好；后端模型切换接口未就绪时不会真正换模型 |
| 用量统计数字像示例 | 后端用量接口不可用时会明确显示“示例数据”，token 为估算；以接入后的真实数据为准 |
| 搜索/置顶后刷新丢失 | 搜索和置顶偏好存在当前浏览器；换浏览器或清本地数据会重置（置顶不生效问题已修复） |
| Python 任务失败 | 检查是否配置了 Python、是否在只读模式、是否通过审批；报错会带 `python_missing` 等原因 |
| 轨迹/计划/通知/模型切换没反应 | UI-2 是前端骨架，后端对应接口未就绪时会提示“暂不可用/已降级”；不是操作失败被静默吞掉 |
| 子任务执行者设置后没变化 | 后端执行者配置接口未就绪时只保存本地偏好；实际执行者以服务端为准，接口就绪后自动生效 |
| 记忆页是空的 | 记忆 v0.3 接口未就绪或该会话/实体没有记忆；页面会提示空态，不展示示例数据 |
| 团队页没有团队 | V0 没有团队记录属预期；V1/V2 模板实例化后出现成员；团队页只读，创建/换负责人走对话 |
| 召回不命中/反复追问 | R2 默认开启 2 跳+agentic；查询太模糊时会追问，可补充实体名/关系；召回 trace 仅 `-debug` 本机可查 |
| 记忆自动巩固会不会改原文 | 不会；巩固写候选/记忆并保留来源，原文与冲突仍保留；默认阈值 8/300s，可配置关闭 |
| 视图编辑器保存失败 | M28 编辑器只允许受控字段/白名单 patch；后端 4xx 会定位到块/字段；刷新拿最新 baseVersion 再保存，不伪造成功 |
| 便携包安装/升级/恢复失败 | 先看 [`deploy/INSTALL.md`](../deploy/INSTALL.md)；升级失败会自动回滚（若未禁用），恢复会先做 pre-restore 备份 |
| 自定义视图打不开/显示表格 | 当前会话没有视图，或视图 schema/绑定失败被降级；让司墨在对话里重新生成/修正 |

## 20. 一分钟上手清单

1. 配好模型 Key，`.\simo.exe serve` → 打开 `http://127.0.0.1:8787`；
2. 说一件具体的事；它边回边在后台推进；
3. 右栏「任务」看工作流/任务，逐条汇报、暂停/恢复/取消；
4. 顶部「文件」看产物和附件，「历史」时间轴跳转，「概览」看自然汇报并手动更新；
5. 让它"导出 PDF/Word/Excel/PPT/图片"；文件出现在「文件」里；
6. 让它"用 Python 处理这份数据/跑个脚本"；首次会请你审批，只读模式下不能执行；
7. 让它"搜索/打开链接"；首次会请你审批；
8. 左栏「定时任务」建一条每天/一次的任务；
9. 用 `Ctrl/⌘+K` 打开命令面板切会话/改权限/看用量；左栏搜索/星标置顶；
10. 左栏「记忆」看类型/实体/冲突/智能体记忆/金字塔；「团队」看成员/状态/模板并进入成员会话；
11. 在对话里让司墨"生成一个自定义视图"；设置/命令面板「自定义视图」打开只读预览，点「编辑」用 M28 受控编辑器改，回滚会生成新版本；
12. 需要便携安装/升级/备份恢复时按 [`deploy/INSTALL.md`](../deploy/INSTALL.md) 操作；
13. 需要改权限时点顶栏「权限」，高风险审批卡片上点允许/拒绝。
