# M11 实现契约：会话工作台（文件 / 历史导航 / 会话概览）

> 前置：M10（工作流编排）已上线。会话=工作区，不引入独立 workspace。
> 本文锁定 M11 三个用户可见功能。

## 1. 文件选项卡

### 1.1 范围
- 本会话的**文件**：任务产物（artifacts）、消息附件（uploads）、必要时 workspace 生成文件；
- 不复制文件；同一文件只出现一次（按路径去重）；
- 只读展示 + 预览/下载；上传入口在输入框（已有）。

### 1.2 API
`GET /api/sessions/{id}/files` →
```json
{"ok":true,"files":[
  {"id":"file-…","kind":"artifact|upload|workspace","name":"report.md","mime":"text/markdown",
   "size":1234,"createdAt":123,"source":{"taskId":"…","messageId":"…","path":"workspace/…"},
   "previewUrl":"/api/artifacts/…/content|/api/uploads/…","downloadUrl":"…"}
],"total":1}
```
- `kind` 过滤：`?kind=artifact|upload|workspace`；
- 预览：文本/Markdown、图片；其它给下载；
- 路径校验/防穿越沿用现有实现。

### 1.3 UI
- 会话顶部标签：**对话 / 文件 / 概览**（或右侧面板「文件」tab；二选一，推荐顶部标签）；
- 文件列表：名称、类型、大小、时间、来源（任务/消息）、预览/下载；
- 空态："这个会话还没有文件"；加载/错误态。

## 2. 历史导航

- 会话消息侧边**迷你时间轴**（每条消息一个小横杠，可按用户/助手区分）；
- 点击横杠：预览该消息摘要（1–2 行），并**跳转**到对应消息（滚动+高亮）；
- 当前视口位置高亮；
- 长会话可折叠/展开时间轴；
- 后端支持分页：`GET /api/messages?sessionId=&before=<msgId>&limit=`（缺省沿用现有全量，兼容）；
- 搜索（M11 可选）：`GET /api/messages/search?sessionId=&q=` 返回命中消息 id + 摘要。

## 3. 会话概览（只读 Spec）

### 3.1 内容
只读，展示：
- **目标**：这个会话在做什么（自然段）；
- **约束**：限制条件（自然段或列表，每项完整句子）；
- **现状**：目前进展到哪（自然段）；
- **已完成**：做完了什么（**列表，逐项勾选 ✓**，每项完整句子）；
- **待办/未开始**：还需要做什么（**列表，逐项未勾选 ☐**，每项完整句子）；
- **备注**：风险/决定/注意（自然段或列表）；
- **时间线**：**有序列表 + 时间**，每项是"时间 + 一句完整的话"。时间粒度按新旧自动概括：
  - 24 小时内：`HH:mm`（如 `14:32`）；
  - 超过 1 天、1 个月内：`M月D日`；
  - 超过 1 个月、1 年内：`YYYY年M月`；
  - 超过 1 年：`YYYY年`。
  - 越老的进度越概括；排序从新到旧或从旧到新固定一种。

> 用户补充要求（2026-11-07）：已完成/待办/时间线必须列表展示，不要整段；已完成勾选、待办未勾选、时间线有序；每项仍是完整句子。**时间线必须带时间，且越老越概括**（24h 内精确到分、超 1 天到日、超 1 月到月、超 1 年到年）。

### 3.2 风格（用户硬要求，design/10 §42）
- **自然、流畅的汇报体**，像秘书当面汇报；
- **不要**关键词短句堆叠（禁止"目标：X／约束：Y"这种电报体）；
- 讲要点，不写流水账；必须列举时，每条也是完整句子；
- 详情可折叠。

### 3.3 生成与刷新
- 数据来源：Spec（目标/验收键/证据）+ 任务/工作流状态 + 关键事件 + 记忆；
- **时间线由后端从事件生成** `[{at,text}]`：`at` 取事件时间戳（任务创建/完成、工作流结束、关键消息等），`text` 由模型把事件改写成一句完整的话；模型失败时用事件标题兜底（不丢条目）；
- **打开时读缓存**（`session_overviews` 表），不每次调模型；
- **"更新概览"按钮**才触发模型重算（`POST /api/sessions/{id}/overview/refresh`）；
- 概览**只读**：修改通过对话完成（秘书改 Spec/任务，刷新后更新）。

### 3.4 API
- `GET /api/sessions/{id}/overview` → `{ok:true, overview:{goal,constraints[],current,completed[],pending[],notes,timeline:[{at,text}],updatedAt,version}}`（无则 204/空对象）；
- `POST /api/sessions/{id}/overview/refresh` → 生成/更新，返回同一结构；
- 概览不对外暴露 Spec 字段名（不出现 specId/specVersion 等）。

## 4. 边界
- 不做独立工作区；不做文件编辑（只预览/下载，编辑走对话/工具）；
- 概览只读；不做多人协作；
- 不做跨会话全局文件库（后续 P2）。

## 5. 验收（M11）
1. 会话产生任务产物 + 上传附件 → 文件选项卡列出，预览/下载可用，去重正确；
2. 历史导航：≥30 条消息时可点击横杠跳转、当前高亮、摘要正确；
3. 概览：点击"更新概览"生成**自然汇报体**文本；刷新页面后读缓存；修改通过对话后刷新可见；
4. 概览不出现 Spec 内部概念；只读（无编辑控件）；
5. `go vet/test`、`tsc`、构建、M1–M10 evals 全绿 + M11 新 case；
6. 会话树/任务/记忆页面不回归。
