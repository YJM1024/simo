# AC-CONV-007-02 真机取证（2026-11-22）

服务为 8787 的 conv6 构建，浏览器为 127.0.0.1:9223 上的 Headless Chrome 157，细指针环境实测 `matchMedia('(pointer: fine)')` 为 true、`(pointer: coarse)` 为 false。主会话渲染 75 条消息与 75 个 `.tl-bar`，只有一个 `.tlg-session` 分组。测量时中栏宽 720，时间轴 gutter 位于 x=358、宽 44，`overflow-x: hidden`、`isolation: isolate`，刻度中心间距实测 6px。

## 四角与有效命中区

取靠上（index 1）、中间（index 37）、靠下（index 73）三个条，条矩形均为 20×4，计算样式 `::after` 为 48×44、`z-index:-1`。以条中心为原点探测 (±24, ±22) 四角，三个条的 12 个点全部命中 `DIV.chat-body`，`closest('.tl-bar')` 为空；原因是 ±24 已超出 44px 宽的 gutter，48px 的命中块左右各被裁掉 2px。把点收进 44×44（±21, ±21）后，上边两点能否命中自身取决于该侧是否被裁（条 37 两点都中自身，条 1 左侧点落到 chat-body），下边两点没有一次命中自身：条 37 落到 44（+7）、条 73 落到 74（+1）、条 1 右侧落到 8（+7）。三个条都没有四角全中自身。

在条 37 的名义 44×44 区域内按 7px 步长取 49 个点：7 个点命中自身（14.3%），33 个点命中别的条，9 个点落在没有条的元素上。沿中心横轴逐 0.5px 扫描，连续归属自身的宽度为 20px（-10.5 到 +9.5）；沿纵轴为 4px（-2.5 到 +1.5）。命中块的名义尺寸是 48×44，实际能被该条接住的区域只有视觉条 20×4 加顶部两侧各约 10×6 的窄条，远小于 44×44。

## 命中解析机制

`.tlg-track` 与 `.tlg-session` 是宽 22.8、覆盖整条轨道且参与定位层绘制的元素，绘制顺序高于 `z-index:-1` 的命中块，因此 gutter 中间那一列在视觉条之外会先命中外层容器。gutter 两侧的空白由所有条的 44px 命中块重叠覆盖，后出现的兄弟节点绘制在上，点 (cx+14, cy) 命中 index+3 的条，(cx+20, cy+18) 命中 index+6 的条，下边缘最多到 index+7。视觉条自身仍是最高层，所以点中心能命中自己。

## 点击跳转

点击条 37（声称 01:22）中心 +20、+18 的点，事件目标与 `elementFromPoint` 都是 index 43（02:54）。`scrollTop` 从 6351 变为 3763，`is-current` 落在 index 43，视口顶部消息为 DOM 第 43 条 `msg-903d4e6c0b7616fa`（文本以“收到标识 FE009C-…”开头），相对被点条偏差 +6 条。作为对照，点条 37 的几何中心后 `scrollTop` 为 3255，`is-current` 为 index 37，顶部消息同为 DOM 第 37 条，偏差 0。

在 1280 宽下复核，时间轴 gutter 位于 x=260、宽 44，条仍为 20×4、`::after` 仍为 48×44，四角 (±24, ±22) 仍全部落到 `DIV.chat-body`。

## 判据

“桌面细指针下命中区至少 44×44”不成立：名义覆盖块 48×44，被 gutter 裁成 44×44 后又因重叠与容器遮挡，实际归属该条的连续区域只有 20×4，四角没有一个点落在该条上。“点击能跳到对应消息”只在点中 20×4 视觉条时成立；点在其名义 44×44 范围内的偏移点会跳到 +1 至 +7 条之后的消息。两项均不满足，AC-CONV-007-02 判 fail。
