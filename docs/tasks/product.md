#### P9.7 中栏宽度拖拽（优先级 P2，暂不实现）

- **来源**：Lead，2026-11-12；用户提出，先记录需求，不改代码。
- **需求**：
  - 中栏消息列表与输入框（Composer）支持拖拽调整宽度，两者始终同宽；
  - 最宽可铺满整个中栏（到右栏/中栏边界），不得溢出；
  - 最窄有下限：桌面建议不低于 **480px**；375 视口以行宽为准（左右各 8）；
  - 拖动时时间轴 gutter、右栏、Composer 与消息白卡保持对齐；时间轴不参与宽度计算；
  - 宽度可持久化；会话级或全局待产品定（本 spec 不锁定）；
  - 暂不实现，不进入本轮 P0–P5；待产品确认持久化范围与交互细节后再立 F 任务。
- **验收草案**：
  - 拖拽只改变 `--chat-column` 宽度，消息白卡/Composer 同宽同中心；
  - 最小/最大边界不可越界；375 不裁切、无横向滚动；
  - 时间轴 gutter 跟随左缘；右栏不被挤动/遮挡；
  - 拖动中有手柄/光标反馈，松开后布局稳定；可选键盘调整（待定）；
  - 刷新/重开后宽度按确认的持久化范围恢复；
  - 页面不写定制 CSS；宽度 token 仍由单一来源管理。
