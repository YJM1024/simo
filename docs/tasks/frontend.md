## 页面复用规则（硬约束）

- 页面只允许：布局原语（grid/flex/间距）+ **已登记组件**；
- 禁止页面内写定制 CSS、内联 style、`className` 里的一次性视觉组合（颜色/边框/圆角/字号/阴影）；
- 需要新样式时：先判断能否用现有组件的 variant 解决；不能 → 先在组件库新增/扩展 variant，登记画廊，再使用；
- 一个组件只允许一套固定变体，不允许页面通过覆盖 class 改样式；
- 页面文件里不出现 `<style>`、`.css` import（全局样式除外）、`style={{...}}`；
- 验收时检查：页面级 CSS 变更应接近 0；新增视觉必须落在 `components/`。

## 组件画廊规范（长期要求）

- 布局：**左侧固定导航栏 + 右侧独立滚动内容区**；
- 左栏列出所有组件小节（按钮、输入、Tabs、Badge、会话行、消息、时间轴、Composer、卡片、右栏概览、空/加载/错误、弹窗、Tokens、Statusbar）；
- 右栏可上下滚动；**左栏不动**；
- 右栏滚动时，左栏对应小节自动高亮（scrollspy），点击左栏平滑滚到对应小节；
- 页面不得因全局布局 `overflow:hidden` 而无法滚动；画廊自身页面要覆盖为可滚动；
- 移动端：左栏收起为顶部横向导航或抽屉，右栏仍可滚动；
- 新增组件必须先在本页登记，再进页面。
