## 1. 当前能力清单

### 1.1 基本形态

- **本地 Web 应用**：单二进制 `simo.exe`（Windows x64），内嵌前端，一条命令启动；
- **只监听本机** `127.0.0.1:8787`，数据在本机 `SIMO_HOME`；
- **单实例**：同一数据目录只允许一个进程；SQLite 持久化；
- **一位司墨**：用户只跟一个司墨对话；执行由工作流/任务推进；会话负责人通过 agents/owner 接口配置（默认 `simo`）。

### 1.2 对话与工作流

- **连续对话**：随时发消息、即时回应；**发消息不打断后台工作**，只有显式"停掉/别做/改成…"才调整；
- **撤回**：流式中未完成的回复可撤回，已完成不撤回；撤回不影响后台任务；
- **工作流**：一次需求可拆成多个任务，按依赖自动推进（默认并发 3）；**每个任务完成都单独汇报**；支持暂停/恢复/取消、单任务取消/重试；
- **任务面板**：按执行中/待开始/已完成/失败分组，按工作流聚合，显示进度、阶段、耗时、产物、汇报入口。

### 1.3 会话工作台

- **三栏 + 会话顶部标签**：对话 / 文件 / 概览；
- **文件**：聚合任务产物、消息附件、工作区文件；去重、预览、下载；只读；
- **历史导航**：消息迷你时间轴，点击摘要跳转/高亮；长会话分页加载更早消息；
- **会话概览**：只读、自然汇报体（目标/约束/现状/已完成/待办/备注/时间线）；打开读缓存，「更新概览」才重算。

### 1.4 文件与内容

- **富文本**：Markdown 子集（标题/列表/代码/引用/表格/链接），原始 HTML 转义；
- **上传**：单文件 ≤20MiB、单消息 ≤5 个；附件随消息、可预览/下载；
- **生成**：PDF（Chrome/Edge headless）、Word/Excel/PPT/图片（内嵌 Python helper + python-docx/openpyxl/python-pptx/Pillow）；生成文件进「文件」页；
- **联网**：`web_search`（DuckDuckGo→Bing）、`web_fetch`（http/https、SSRF 防护、2MB/15s）；来源链接展示；
- **Python 执行（M17）**：`run_python` 支持直接代码或 workspace 内脚本、参数、超时（≤120s）；cwd=workspace，输出 `[exit code: N]`，**需审批**，环境不继承 Key，超时杀进程树，>64KB 落盘。

### 1.5 权限与工具

- **沙盒模式**：只读 / 工作区可写（默认）/ 完全访问（二次确认）；
- **审批策略**：每次询问 / 自动（默认，只读自动、写/执行/网络询问）/ 从不询问（需审批动作直接拒绝）；
- **审批动作**：允许一次 / 本会话允许 / 拒绝；支持单次提权（只宽一档、需理由、仅本次）；
- **工具**：`read` / `glob` / `grep` / `write` / `edit` / `pwsh`（默认 120s 超时、进程树终止、输出过大落盘、环境不继承 Key）、`run_python`、`make_*`、`web_*`；
- **审计**：工具调用与审批写入事件日志。

### 1.6 记忆、归档与主题

- 结构化记忆 + 只读记忆页；冲突可见；修改通过对话；
- 会话可归档为只读、可恢复，不删数据；跨会话按需取用产物（不复制）；
- 浅色科技风 `theme-light-tech`；设置中心有主题入口，但当前只有一套。

### 1.7 定时任务

- 左栏「定时任务」入口；支持一次/间隔/每天/每周/cron、时区、目标会话；
- 启停、立即运行、编辑、删除；
- 到点在目标会话执行并汇报；停机错过只补最近一次；需审批无人应答则暂停并汇报（fail-closed）。

### 1.8 UI-1：界面增强 + 用量统计

- **命令面板**：`Ctrl/⌘+K`，混合搜索会话与命令；切会话/新建/改权限/打开设置/打开用量/暂停/切主题；
- **斜杠命令**：`/archive`、`/rename <标题>`、`/pause`、`/model <名称>`；
- **@ 引用**：输入框选择会话/文件，插入文本引用；
- **消息操作**：复制、引用/回复、重试；流式回复可撤回；
- **会话搜索/置顶**：左栏按标题/摘要/id 搜索，星标置顶；偏好存当前浏览器；
- **交付物卡片**：会话顶部展示最近产物（最多 4 个），预览/下载；
- **设置中心**：模型偏好（本地）、权限、主题、数据目录、快捷键；
- **用量统计**：树状表格（每行一个会话，按树缩进、含负责人头像、父行汇总）+ 每行 sparkline；指标（消息数/token）、粒度（天/周/月）、范围（7/30/自定义）；
- **首启引导**：首次打开显示一次（对话/任务/记忆·智能体/命令面板），关闭后可在设置看快捷键。

### 1.9 M18：Spec 驱动执行

- 每个会话 1:1 内部 Spec（**用户不可见**），状态机 `draft → confirmed → planning → executing → verifying → verified → archived`，可 reopen；
- 执行循环每轮读取目标/约束/当前/验收键，决策/任务/汇报后更新；任务挂 `acceptance_keys`，完成写 evidence；
- **概览由会话目标与任务状态生成**（只读），不展示内部执行字段；
- 子任务执行者默认「任务智能体 NPC（空人格）」，可配置为「司墨本人」；设置页可切换（后端接口未就绪时仅本地偏好）；
- 新增 `spec_transitions` / `spec_evidence` 等内部表，自动迁移（详见管理员指南）。

### 1.10 M23 / UI-2：深度视图前端骨架

- **轨迹视图**（对话/轨迹切换）、**工具调用卡片**（命令/输出/diff/审批/产物）、**计划与待办**、**模型/推理选择器**、**压缩可视化**、**通知中心**；

### 1.11 M21：记忆 v0.3（记忆浏览器）

### 1.12 M22：召回层

## 2. 里程碑摘要（M1–M41 + UI-1/UI-2）

| 里程碑 | 一句话 |
|---|---|
| **M1 基础骨架** | 单二进制 + 三栏壳 + 流式对话 + 持久化 + 断线续接；事件日志/检查点/token 计量。 |
| **M2 对话核心** | 接真实模型；连续对话、撤回重答、纠偏、并行任务、权限判定骨架。 |
| **M3 记忆地基** | 记忆条目/作用域/候选合并/冲突/FTS5 检索/只读记忆页。 |
| **M4 会话树与主窗口** | 会话树、消息归属、聚合视图、会话标签跳转、改名、自动建下级会话。 |

## 5. 已知限制

### 5.1 安全与部署

- **无鉴权、仅本机**：默认只监听 `127.0.0.1:8787`；不要直接暴露到局域网/公网；
- 没有多用户/多租户/HTTPS/远程审计；
- **容器未实测**：`deploy/` 提供 Dockerfile/compose，但开发机无 Docker/WSL/Podman；容器内 Chrome/Python 依赖也未验证；
- 无自动更新；升级需手动替换二进制并备份。

### 5.2 模型与执行

- 真实模型只接 DeepSeek `deepseek-flash`，其他 provider 未接入；
- **模型选择器/`/model` 目前是本地偏好**：后端模型切换接口未就绪时只记录选择，实际模型仍由后端决定；
- 沙盒是**路径策略 + 环境清理 + 审批**，不是完整 OS 级隔离；`run_python` 同样不是 OS 沙箱，Python 代码本身仍可执行其语言能力，只运行可信代码；
- 复杂长任务仍可能失败/中断；失败会如实汇报，不静默；
- 没有多智能体团队（团队 V0/V1/V2 为后续契约）；没有事件触发/webhook（P2）。

### 5.3 文件与网络

- Office/PDF 不做在线预览（下载后用本机阅读器/Office 打开）；图片可预览；
- 文件生成依赖本机 Chrome/Edge + Python 文档库；缺失时明确报错，不静默降级；
- 搜索用公开 HTML 结果，无第三方搜索 API Key，质量依赖页面结构；
- `web_fetch` 拒绝内网/本机地址（SSRF 防护）；有 2MB/15s 限制；
- 上传单文件 ≤20MiB、单消息 ≤5 个；不支持 WYSIWYG/外部图片渲染。

### 5.4 Python 执行

- 依赖 `SIMO_PYTHON`/`tools.python` 或 PATH 中的 Python 3；缺失返回 `python_missing`；
- 只接受 `code` 或 workspace 内 `path`；`args`/`timeout_ms` 可选；超时 ≤120s；
- 执行类审批（R2）；`read-only` 直接拒绝、`never` 直接拒绝；审批无人应答 fail-closed；
- 输出 >64KB 落盘；环境不继承 Key；但**未做网络/文件系统级子沙箱**。

### 5.5 定时任务

- 依赖服务进程常驻；服务停止期间不触发；
- 停机错过只补**最近一次**，不补历史；
- 需要审批但无人应答会暂停并汇报（fail-closed）；
- 只做时间触发；事件触发/webhook 属 P2。

### 5.6 UI-1 已知限制

- **@ 引用是纯文本引用**：只插入 `@标签` 文本，不建立结构化“消息/文件引用”关系；理解依赖模型读文本；
- **`/model` 本地**：仅记录模型偏好；后端切换接口未就绪时不真正换模型；设置中心同理；
- **用量示例降级**：后端用量/会话接口不可用时显示**示例数据（source=sample）**；即使接口可用，token 也可能标注为“估算”；不是账单；
- **会话搜索/置顶是本地偏好**：存当前浏览器，换浏览器/清本地数据会重置；
- **不做 fork/插件**；子代理状态并入任务面板；组件级测试未引入；
- 主题只有 `light-tech` 一套；256 主题/主题市场式扩展属 P1。

### 5.7 M18 执行/内部 Spec 限制

- Spec 是会话内部实现，**对用户不可见**；没有公开 Spec API/页面；概览只读、由目标与任务生成，不能直接编辑；
- 子任务执行者设置（NPC/司墨）在后端配置接口未就绪时只保存本地偏好；实际执行者以服务端为准；排障可用 `-debug` 的 debug hooks（仅 loopback）；
- `spec_transitions`/`spec_evidence` 等表属于内部执行层，升级前须备份；不要手改表结构。

### 5.8 UI-2 前端骨架限制

- 轨迹/计划待办/模型切换/通知持久化等后端接口多数未就绪，前端会显示“暂不可用/已降级”，不是所有能力都已打通；
- 通知中心后端未就绪时历史只在当前页面内存，刷新不保留；不接浏览器通知/声音；
- 计划确认/待办打勾依赖后端动作层；未就绪时可能无法操作或提示不可用，不会本地改任务状态；
- 压缩可视化依赖 `context.compacted` 事件；无事件时不会显示；
- 模型选择器只记录本地偏好，不真正改变后端模型（除非后端接口就绪）。

### 5.9 M19 运行时 API

- `GET /api/runtime/status`、`/api/workflows/{id}/runtime`、`/api/tasks/{id}/runtime` 是可观测性接口，M19 已上线；
- `recovering`/`remaining` 等字段在部分场景仍可能是近似/占位值；恢复、预算与失败接管以实际任务/事件为准，不据此承诺无限长程可靠性。

### 5.10 M21–M41 已知限制

- **记忆**：记忆页只读；冲突不自动裁决；写/忘记仍通过对话；`SIMO_MEMORY_V3=0` 可回退旧读路径；
- **召回**：M22/M27 召回主要是内部能力/`-debug` 本机入口，普通 UI 不直接展示 recall trace；R2 默认开、**向量默认关**（M32 本地字符 n-gram TF-IDF，需 `SIMO_RECALL_VECTOR=1` 且重建索引）；召回质量与实体/关系覆盖相关；
- **M32 向量**：本地 TF-IDF 不是神经网络嵌入；索引表 `recall_vectors`/`recall_vector_terms` 只随 rebuild/增量维护；未启用/未重建时向量路径降级；
- **M33 交互**：表格排序/分页是展示状态，不写库；看板移动失败保留原列、不乐观改状态；编辑器块搜索/删除确认/未保存提示仅前端安全护栏，最终仍以后端校验/审批为准；团队筛选/搜索只作用于只读列表；
- **M34 复杂交互**：多步向导/多列排序/行内编辑/批量/图表/看板 WIP 泳道为受控实现；失败保留原状态，但仍受 schema/动作权限约束；`chart` 为纯 SVG 最小图表，不是通用 BI；
- **M35 CI**：本地 `deploy/ci.ps1` 与 GitHub Actions 已提供；docker job 可选、本机无 Docker 不判失败；real-smoke 依赖 secrets，CI 结果以实际运行日志为准；
- **M36 容器**：`deploy/CONTAINER.md`/`docker-build.ps1` 已提供，但本机无 Docker/WSL/Podman，镜像构建/运行仍**未实测**；安装见 `deploy/DOCKER-INSTALL.md`；
- **M37/M38 导航/布局**：顶部 6 个全局视图 + 页内 mainView；文件是会话子标签；右栏细竖条可收起/固定/拖拽，宽度本地保存；窄屏右栏浮层、≤820 单列；复杂拖拽/多窗口不在本期；
- **M40 视觉**：组件层覆盖常用控件，但组件级自动化测试仍有限；可见正文≥13px、近黑文字、线性图标；概览最多 6 条（超出“另有 N 项”）；时间轴 32px 点击/键盘跳转；
- **M41 卡片**：卡片复用视图块/动作目录，但只支持本会话、消息内；R3+ 审批、R4 从卡片直接拒绝；重启时未知副作用不自动重试；fallbackText 必需；卡片不是通用页面编辑器；
