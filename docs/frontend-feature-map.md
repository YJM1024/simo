# 司墨前端功能 → 新布局映射（M67 重写前基线）

> 目的：按 `frontend/prototype4/` 重建视觉时，逐条确认旧功能不会丢失。
> 新结构：**264px 侧栏（贯穿全高） + 右侧主区域 [单行顶栏 → 上下文条 → 聊天/页面 → 状态栏]**。
> 所有入口均使用 prototype4 的 `s-*` 组件与新 tokens；下列“新位置”是待实现目标位置。

## 1. 全局壳层 / 侧栏

| 旧功能 | 新位置 / 入口 | 说明 |
|---|---|---|
| 品牌「司墨」+ 版本 v4.1 | 侧栏顶部 `.s-brand` | 小方标 + 文字 + env；不再出现在顶栏 |
| 工作区选择 | 侧栏品牌下 `.s-ws` | 仅名称「主工作区」+「本地环境」+ chevron；不再有子标题 |

| 置顶 / 取消置顶 | 会话行 hover 操作 | 保留 |
| 重命名 | 会话行 hover 操作 | Enter 保存 / Esc 取消 |

## 10. 需要确认 / 暂无新落点

1. **模型手动选择**：M53 已按需求固定 V4.1 Flash（只读），不再有模型下拉；如要恢复，需要新位置（智能体页？）。
2. **后端真实 token 用量**：当前代码/接口没有稳定 token 总量，侧栏用量卡将显示会话数占位，而非伪造百分比/额度。
3. **旧「概览」中栏视图**：已迁移到 Inspector 概览，不再有中栏独立概览页。
4. **文件/轨迹 tab 的三级内容**：保留数据与组件，位置改到聊天列顶部窄 tab；若确认可去掉入口则删除。
5. **右侧 Inspector 拖拽宽度**：原型固定 324px；若保留拖拽需额外确认（默认不保留，以原型为准）。
6. **旧 UI kit 的公开组件 API**：重写后仅保留页面真正使用的导出；不再提供旧视觉组件。
