# SKILL · release-checklist

## 何时使用

- 一批变更通过 Verify，准备出包/上线（8787/容器/便携包）；
- 需要版本号、发布说明、包/hash、回滚与 smoke；
- 任何面向用户的发布，包括小版本。

不用于：发布前需求/实现阶段；事故止血（先走 SCENARIOS 事故，发布后补）。

## 输入

- 已通过的 spec/AC/证据；
- 变更范围/风险/迁移版本；
- 目标环境、版本号策略、回滚包/备份；
- 已知问题/兼容性说明。

## 步骤

1. **范围冻结**：列出本版变更/不包含项；阻塞缺陷清零；
2. **全量门禁**：tsc/build/test/evals/截图/回归；未跑项标注；
3. **迁移**：备份/演练/停服窗口（如有）；回滚点；
4. **打包**：可复现包/镜像；无密钥/临时文件；记录 SHA256/大小；
5. **说明**：发布说明、已知问题、升级/回滚步骤；
6. **部署/发布**：目标环境 smoke（健康检查、关键 API/UI、真实数据）；
7. **发布后**：监控/日志/用户反馈；归档证据。

## 产物

- Release checklist + 版本/范围/已知问题；
- 包/镜像 + SHA256 + 大小 + 构建时间/commit；
- smoke 结果/截图/健康检查；
- 回滚包/备份/命令；
- 发布后监控记录。

## 检查表

- [ ] 范围冻结，阻塞缺陷清零；
- [ ] 全量门禁通过，未跑项有豁免记录；
- [ ] 包无密钥/调试文件；hash 可复算；
- [ ] 目标环境 smoke 通过（不是本地替代）；
- [ ] 回滚包/备份可用，步骤演练；
- [ ] 发布说明含已知问题/升级说明；
- [ ] 发布后监控/反馈有人看。

## 反模式

- “本地通了”直接上线；跳过 smoke；
- 带密钥/临时文件打包；hash 不记录；
- 没有回滚包/回滚命令；
- 发布说明只写“优化/修复若干”；
- 发布后不看监控，等问题来找。

## 示例

> M41 发布：冻结范围 → 144 evals 131/131 + 13 PENDING（12 脚本）/real-smoke 41,524 → 包 `simo-M41-win-x64.zip` 11.61MB/SHA256 → smoke 8787 健康/关键路径 → 回滚包与备份 → 归档 release notes/evidence。
