# 智能体工作纪律（硬性）

> 2026-11-08 用户明确要求。所有 Lead 与队友、所有工具/脚本/测试必须遵守。

## 1. 只改工作区

- 唯一允许写入的根：`E:\dsh_home\workspaces\agent\`
- 允许的额外数据目录：`<工作区>\data\`（AGENTD_HOME）
- **禁止**修改、创建、移动、删除工作区外的任何路径（用户目录、AppData、系统目录、其他项目）。
- 读取（只读）工作区外文件需明确目的；写入一律禁止。

## 2. 禁止递归删除

- 禁止 `Remove-Item -Recurse`、`rmdir /s`、`del /s`、`rm -rf`、`git clean -fdx` 等对**任何目录**执行。
- 不得按进程名 kill；只能停自己 `-PassThru` 的 PID。

## 3. 删除 = 先移到工作区回收站

- 需要清理时，把目标**移动到** `.trash\<yyyyMMdd-HHmmss>\<原名>\`（工作区内），保留原样，不直接删。
- 确认删除回收站内容前，必须向用户说明："这是临时目录/回收站内容，只删这一处"，得到同意后才可删除**该目录下的内容**。
- 临时目录只在工作区 `.tmp\` 下用 GUID 新建；不使用系统 Temp 存放需要清理的内容。

## 4. 测试与评测

- 独立端口 + 独立 `AGENTD_HOME`（工作区 `.tmp\` 下 GUID）。
- 不碰用户实例 `simo-live.exe` / 8787。
- 脚本先做路径前缀校验（必须落在工作区或 `.trash`），否则拒绝执行删除/移动。
- **评测类任务不得请求用户审批**（用户明确要求：不要因等待批准而卡住任务）；改为自动执行，但写入范围**只能在工作区内**，工作区外一律只读且禁止写入/删除/移动。
- 评测所有产物（日志、临时 home、报告、脚本）都放在工作区 `.tmp\` 或 `evals/reports/`；不得使用系统 Temp 存放需清理内容。

## 5. 复核

- Lead 派工时在任务描述里写明上述约束；完成后复核 diff 与路径。
- 违反一次即停止该队友，由 Lead 接管修复。
