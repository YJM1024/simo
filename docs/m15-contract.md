# M15 实现契约：消息回复（引用） + 产品名「私默」 + 品牌图标

> 前置：M14 完成后开工。用户三条要求。

## 1. 消息回复（引用）

### 1.1 数据
- messages 增 `reply_to_id TEXT`（chat migration v11，可空）。
- `POST /api/chat`、WS `chat` 接受 `replyToMessageId`（可空）。
- 消息响应增 `replyTo`（快照，避免前端翻页丢失）：
  ```json
  {"id":"msg-…","role":"user|agent","text":"引用摘要（≤200字）","sessionId":"…","sessionTitle":"…"}
  ```
- 允许回复**任意消息**：agent 的、自己的（user）、同会话或聚合视图里其他会话的消息（跨会话引用允许，快照带 session 标题）。

### 1.2 模型上下文
- 后端把引用内容作为**明确的上下文数据**注入模型可见文本（不当作指令）：
  ```
  [引用回复] <role>：<text 摘要>
  <用户本条正文>
  ```
- 引用只影响本轮理解，不改变历史消息归属。

### 1.3 UI
- 消息 hover 操作：**回复**按钮（agent 与 user 消息都有）。
- 输入区：正在回复时显示引用条（角色 + 摘要 + 取消），发送后清空。
- 消息气泡：正文上方显示引用卡片（点击可跳转到原消息）；跨会话引用显示会话路径。
- 键盘可达（按钮 aria-label、Esc 取消引用）。

## 2. 产品名统一为「私默」

- 所有**用户可见**文案：`秘书` / `本地秘书` / `司墨` / `agentd`（显示用途）→ **私默**；
- 覆盖：界面（顶栏品牌、状态文案、提示语、错误提示）、用户文档、README、发布说明、部署文档；
- 保留内部标识不变：Go module `agentd`、`AGENTD_HOME`、可执行文件 `simo.exe`、API 路径；
- 说明：内部名不变是为了兼容数据与脚本，用户无需感知。

## 3. 品牌图标

- 设计：**圆角方形徽标 + 墨滴/对话气泡**融合（体现"记忆/静默/对话"），主色取主题 accent 渐变；
- 资产：
  - `web/public/icon.svg`（矢量，favicon 与顶栏共用）；
  - `icon-256.png`（Chrome headless 截图生成，备用/分享）；
- 接入：
  - `index.html` `<link rel="icon" type="image/svg+xml" href="/icon.svg">`；
  - 顶栏品牌处用内联 SVG 徽标（不额外请求、随主题变色）；
  - 构建复制 icon.svg 到 dist。

## 4. 验收（M15）

1. 回复 agent 消息 → 发送后气泡带引用卡片、模型回答明显针对该消息；回复自己的消息同样可用；
2. 跨会话引用显示会话路径；引用卡片点击跳转原消息；
3. 全站用户可见文案无"秘书/本地秘书/司墨"，统一"私默"；内部名不变；
4. favicon 与顶栏显示新图标；无图时优雅降级；
5. `go vet/test`、`tsc`、构建、M1–M14 evals 全绿 + M15 新 case。

## 5. 边界

- 不做消息编辑/删除；不做多级嵌套引用展示（只显示直接引用的那一条）；
- 不引入图片生成模型；图标为手绘 SVG。
