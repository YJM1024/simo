## 1 适用范围与位置

本文件规定后端域怎么接契约、怎么建数据模型与迁移、怎么写实现与测试、怎么交证据。适用对象是 `backend/` 下的 Go 代码、HTTP 与 WebSocket 契约、数据库结构与迁移、运行时配置与错误码，以及 `specs/backend/` 下的长期 spec 与变更增量。产品行为定义由产品 spec 判定，界面与交互由前端域判定。

后端处在契约与验收之间。输入是冻结的 AC、契约表的后端列、设计说明与相邻域接口；输出是后端 spec 增量、迁移与回滚证据、接口测试与性能测量结果。后端不改产品行为，也不替验收作结论。

## 3 错误码与状态码

错误响应是前后端与测试共用的契约面。本节规定信封形状、状态映射与不泄露内部信息的判定口径，错误码的业务语义由产品 spec 定义，本节只管编码与状态的一致性。

### MXV2-BE-14 错误响应统一三字段信封

- 规则：所有错误响应返回 `{"ok":false,"error":"<文案>","code":"<错误码>"}` 三字段，HTTP 状态与 code 分别给出；不以纯文本、HTML 或空体作为错误响应。
- 判据：缺 ok、error、code 任一字段的错误响应数为 0；纯文本错误响应数为 0。
- 执行：`script:..\toolchain\go.ps1 test ./cmd/simo -run "TestM7UniformErrorEnvelope" -count=1` 期望退出码 0
- 层级：L1
- 依据：MXV2-7-07、MXV2-5-17
- 适用：所有 HTTP 与 WS 错误出口。

### MXV2-BE-16 越权不泄露资源存在性

- 规则：访问他人或不存在的资源时，返回 403 还是统一 404 由契约按资源类型选定并在错误码表写明；同一资源不得同时存在两种返回，响应文案不出现资源名、资源 id 与「无权限」以外的细节。
- 判据：同一资源出现两种越权返回的条数为 0；403 响应含资源名或 id 的条数为 0。
- 执行：`ai-review:核对越权与不存在两类请求的返回状态、错误码与响应文案`；谁判：安全评审人；误放行：用 403 暴露某个会话 id 存在；误拦截：管理端点按契约明确返回 403 被判为泄露。
- 层级：L1
- 依据：MXV2-5-17、S-059
- 适用：涉及资源归属判断的端点。

## 5 幂等与并发

写请求要能承受重试与并发，判据落在资源 id、响应字段与库内行数三处。SQLite 采用单写多读，连接参数与冲突码必须写进契约，测试按真实并发断言。

- 规则：同一幂等键二次提交返回同一资源 id，响应带 `idempotent:true`，库中只有一行；失败重试要释放占位，不让后续请求永久等待。
- 判据：二次提交返回同一 id 且 idempotent=true 的比例为 100%；库中出现两行的用例数为 0。
- 执行：`script:..\toolchain\go.ps1 test ./cmd/simo -run "TestM76CardActionIdempotentSequential" -count=1` 期望退出码 0
- 层级：L2
- 依据：MXV2-7-05、MXV2-7-03
- 适用：所有幂等写端点。

- 规则：SQLite 连接串固定 `busy_timeout(5000)`、`journal_mode(WAL)` 与 `synchronous(NORMAL)` 三项；并发写冲突的重试次数与退避在契约写明。

## 7 安全

安全判定按 OWASP ASVS 5.0 的编号条款逐条落位，L1 为底线，L2 按产品形态选用并写 N/A 理由。单用户本机形态下 V6 认证与 V8 授权两章整章 N/A，但仍要按月复核该前提是否变化。
