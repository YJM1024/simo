## 1 适用范围与位置

本文件规定后端域怎么接契约、怎么建数据模型与迁移、怎么写实现与测试、怎么交证据。适用对象是 `backend/` 下的 Go 代码、HTTP 与 WebSocket 契约、数据库结构与迁移、运行时配置与错误码，以及 `specs/backend/` 下的长期 spec 与变更增量。产品行为定义由产品 spec 判定，界面与交互由前端域判定。

后端处在契约与验收之间。输入是冻结的 AC、契约表的后端列、设计说明与相邻域接口；输出是后端 spec 增量、迁移与回滚证据、接口测试与性能测量结果。后端不改产品行为，也不替验收作结论。

## 3 错误码与状态码
