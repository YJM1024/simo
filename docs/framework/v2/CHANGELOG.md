# 变更记录

本文件记录框架规则册的结构性变更。日常条文修订登记在 `MOXIAN.md` 附录 C 与附录 D，不逐条抄到这里。

## v2.0.0（2026-11-27，变更包 CHG-FW-002）

### 结构

规则册从十三章加附录改为九章加附录 A 至附录 D。九章依次为目的与范围、术语与编号、角色与授权、流程点链、任务类型与规格分层、规则格式与判定、门禁与证据、验收与发布、异常与回滚。

条目从二百八十五条收敛到一百五十八条。处理方式为改写二百零三条、合并五十六条、保留二十三条、删除三条，新增零条。合并后有一百一十八条被吸收，落地二百七十六条，其中一百一十八条不再单独成条。

每条规则改为固定六字段：规则、判据、执行、层级、依据、适用。执行字段只有两种写法，`script:` 后接命令与期望退出码，或 `ai-review:` 后接判据、谁判、误放行与误拦截。

### 删除

删除三条。原 MX-2-17 的十五道特有门禁责任人被第 7 章门禁规则与 GATES.md 的门禁条目覆盖。原 MX-3-17 的需求点五档状态被四值状态取代。原 MX-7-15 的任务卡五状态同样被四值状态取代。三条的内容在新章里都有落点，删除的是重复表述。

### 附录 D

六条暂不立规，进附录 D。D-01 为生效前已开工任务的补齐方式。D-02 为异常代价计量。D-03 为度量复算与缓存取数。D-04 为迭代五环节是否保留。D-05 为转正四条件是否保留。另有一条机制条款，规定附录 D 的开关方式，不占一百五十八与一百八十的计数。

### 门禁归宿

一百五十八条里，script 四十五条，ai-review 一百一十三条，逐条写进执行字段。原无判据的二十四条门禁全部归位，十四条转为脚本，十条转为人工，旁路零条。R4 复验后 script 由一百二十条降到四十五条（28.5%，接受口径记 29%），取舍理由见 `ACCEPT.md` 第 8 节。

十四条脚本归宿为：原 MX-G-14 至 19 进 `check-trace.mjs` 的 T1 至 T6；原 MX-G-21 至 25 进 `check-spec-language.mjs` 的 L1 至 L5；原 MX-G-58、60 进 `check-evidence.mjs` 的 E-P1 与 E-D1；原 MX-G-63 进 `check-contract.mjs` 的 C1。

十条人工归宿为：原 MX-G-57 由撰写员自判、验收员复核；61 由验收员判；62 由测试或安全评审人判；64 由需求方判；65、66、67 由撰写员判；68 由验收员判；69 由需求方判；70 由发布员判。

脚本共十八个，全部已建并可跑；总册 script 四十五条与 ai-review 一百一十三条都已归位，不再有待建脚本或待补规则。
