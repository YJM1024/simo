# SLO 登记模板（slo）

版本：v1.0，2026-11-25。状态：active。本模板服务 `MOXIAN.md` 第 13 章与第 6 章 MX-6-28，落点 `docs/framework/templates/slo.md`，登记内容同步写进契约表类 1 可观测性列与类 6 告警判据列。

## 1 用途与何时用

新功能、性能优化与可观测性接入在契约冻结前登记三条 SLI：请求成功率、首帧时间、写入 p95。每条 SLI 写口径、采样点、窗口、目标与错误预算，缺一条不得冻结。改动后再登记一次实测值，实测与目标不一致时写偏差原因与处置，不直接改目标。

## 2 字段表

| 列名 | 必填 | 取值口径 |
|---|---|---|
| SLI 编号 | 是 | `SLI-<域>-<NN>`，域内唯一 |
| SLI 名 | 是 | 三条固定：请求成功率、首帧时间、写入 p95；扩展 SLI 另起编号并写理由 |
| 指标口径 | 是 | 分子、分母与排除项逐项写，例如「成功响应数 / 总请求数，排除健康检查」 |
| 采样点 | 是 | 中间件名或代码位置加 span 名称，与 `domains/backend.md` MX-BE-71 的指标名一致 |
| 单位 | 是 | 百分比、毫秒、次每分钟之一 |
| 统计窗口 | 是 | 1 分钟、5 分钟、1 小时三值之一，告警与 SLO 可不同窗口但须分别写 |
| 采样率 | 是 | 百分比，写采样依据；100% 也要写 |
| 目标值 | 是 | 带比较符与数值，例如 `≥99.9%`、`≤1200ms`、`≤300ms` |
| 错误预算 | 是 | 窗口内允许失败量，写绝对值与百分比两种 |
| 告警阈值与持续 | 是 | 阈值、持续时长、通知渠道与抑制条件四项 |
| 判定人 | 是 | 指标口径与采样率由后端（值班）判定 |
| 复核人 | 是 | 测试或验收角色，按 MX-R-40 不得与判定人同人 |
| 偏差与处置 | 是 | 实测值、偏差原因、处置动作与期限；未实测写 `N/A：<理由>` |

## 3 填写示例

| SLI 编号 | SLI 名 | 指标口径 | 单位 | 窗口 | 目标值 | 告警阈值与持续 |
|---|---|---|---|---|---|---|
| SLI-CONV-01 | 请求成功率 | 2xx 与 3xx 响应数 / 总请求数，排除健康检查 | % | 5 分钟 | ≥99.9% | <99.5%，持续 5 分钟，企业微信通知后端（值班），发布窗口内抑制 |
| SLI-CONV-02 | 首帧时间 | 首屏内容绘制完成时间，P75 | ms | 5 分钟 | ≤1200ms | >1800ms，持续 10 分钟，同上 |
| SLI-CONV-03 | 写入 p95 | 写入接口端到端耗时，P95 | ms | 1 小时 | ≤300ms | >600ms，持续 15 分钟，同上 |

## 4 与条款、门禁的引用

- 条款：MX-6-28 规定可观测性列七项与告警判据四项；MX-R-40 规定指标口径、采样率与告警有效性的判定人与复核人。
- 门禁：可观测性门核三条 SLI 与告警判据齐全；证据门核告警触发记录按 `templates/evidence-index.md` 的「可观测性证据」组登记。
- 验收判定：`TASK-MATRIX.md` 第 2.1 节「可观测性接入」行的判定人取本表「判定人」列，不得由实现者填写。
