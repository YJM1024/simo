# 灰度发布记录模板（gray-release）

版本：v1.0，2026-11-25。状态：active。本模板服务 `MOXIAN.md` 第 6 章 MX-6-27 与契约表类 11，落点 `docs/framework/templates/gray-release.md`。发布交付与独立工具在放量前按本表登记，收口时按同一表核对观察结论。

## 1 用途与何时用

每次按档位放量前登记一次：分桶键、档位序列、每档观察窗口、回滚阈值与连续命中次数、判定人。放量中每档结束写一次观察结论，未写结论的档位不得进入下一档。回滚阈值未写连续命中次数或判定人时，发布检查不通过。

## 2 字段表

| 列名 | 必填 | 取值口径 |
|---|---|---|
| 发布编号 | 是 | `GR-<域>-<YYYYMMDD>-<NN>` |
| 发布物与版本 | 是 | 产物名加版本号，与更新清单逐字一致 |
| 分桶键 | 是 | 键名与取模或哈希方式，同一用户重复请求命中同一桶 |
| 档位序列 | 是 | 百分比序列，写起始档；每档对应一行观察记录 |
| 观察窗口 | 是 | 每档时长与单位，写起止时刻 |
| 观察指标 | 是 | 错误率、p95、崩溃率与业务指标，写基线值与来源 |
| 回滚阈值 | 是 | 指标、比较符、数值与连续命中次数，缺连续次数按缺失计 |
| 判定人 | 是 | 每档结论的判定角色；不得为发布执行者 |
| 回滚动作 | 是 | 回退版本号、命令与预计耗时；回滚后校验方式 |
| 灰度与回滚点 | 是 | 哪些档位算灰度、从哪一档起可回退到上一版本 |
| 结论 | 是 | 每档通过、暂停、回滚三值之一，写依据数据 |

## 3 填写示例

| 档位 | 观察窗口 | 错误率 | p95 | 结论（判定人） |
|---|---|---|---|---|
| 1% | `10:00–10:30` | 0.08% | 280ms | 通过（后端值班） |
| 10% | `10:30–11:00` | 0.11% | 300ms | 通过（后端值班） |
| 50% | `11:00–11:30` | 1.4% | 640ms | 回滚（验收）：错误率超 1% 连续 3 个窗口 |
| 100% | 未执行 | 未执行 | 未执行 | 回滚后重新评估 |

## 4 与条款、门禁的引用

- 条款：MX-6-27 规定发布与产物十项；契约表类 11 的分桶键、档位、观察窗口、回滚阈值与连续命中次数与本表一致。
- 门禁：发布检查门核本表字段齐全与每档结论；证据门核观察数据路径；收口门核回滚结论与复测记录。独立工具的发布另见 `TASK-MATRIX.md` 第 8 节「独立工具」表。
- 验收：`TASK-MATRIX.md` 第 2.1 节「独立工具」与发布交付的任务族表判定人取本表判定列。
