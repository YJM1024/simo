# 外部依赖登记模板（external-dependency）

版本：v1.0，2026-11-25。状态：active。本模板服务 `MOXIAN.md` 第 6 章 MX-6-29 与契约表类 1 外部依赖列，落点 `docs/framework/templates/external-dependency.md`。外部依赖门的登记、配额与降级三项按本表核对。

## 1 用途与何时用

引入或变更第三方服务、模型接口、支付与推送渠道时，在契约冻结前填一次，一依赖一行。只写依赖名不写配额与降级的按缺失计；停服窗口与联系人缺失时，变更不得进入出口级。降级方案必须在故障注入中验过一次，未验的写「未验证」并到期日。

## 2 字段表

| 列名 | 必填 | 取值口径 |
|---|---|---|
| 依赖编号 | 是 | `EXT-<域>-<三位序号>`，域内唯一 |
| 依赖名与用途 | 是 | 服务名加调用场景，写官方域名 |
| 版本锁定范围 | 是 | 接口版本或 SDK 版本范围，写 `>=x <y` 或固定版本 |
| 配额窗口与上限 | 是 | 窗口（秒、分、日、月）与请求数或 token 数上限，写来源（合同或文档链接） |
| 限流阈值 | 是 | 触发限流的数值与动作（排队、拒绝、降级） |
| 重试与退避 | 是 | 最大次数、退避序列与幂等键 |
| 熔断与半开 | 是 | 失败率阈值、熔断时长、半开探测次数与恢复条件 |
| 降级行为 | 是 | 降级后用户可见结果、是否缓存兜底、错误码与文案键 |
| 变更通知提前天数 | 是 | 供应商通知到上线的天数；无合同约定写「无」与应对 |
| 停服窗口与联系人 | 是 | 计划停服时段与双方联系人角色，不写私人手机号 |
| 故障注入验证 | 是 | 注入方式（超时、限流、5xx）、命令与结果；未验证写到期日 |
| 判定人 | 是 | 配额与降级由后端判定，测试复核故障注入 |

## 3 填写示例

| 字段 | 示例 |
|---|---|
| 依赖名与用途 | 模型推理接口 `api.example-llm.com`，用于会话摘要 |
| 版本锁定范围 | `v2`，SDK `>=1.8 <2.0` |
| 配额窗口与上限 | 每分钟 600 次，每日 200 万 token，来源为合同附件二 |
| 限流阈值 | 连续 3 次 429 后进入排队，排队超 10 秒转降级 |
| 重试与退避 | 最多 3 次，退避 200ms、1s、3s，幂等键为请求 ID |
| 熔断与半开 | 失败率 >50% 持续 60 秒熔断，熔断 60 秒后半开探测 3 次 |
| 降级行为 | 返回缓存摘要并标「离线生成」，错误码 `summary_degraded` |
| 变更通知提前天数 | 14 天 |
| 停服窗口与联系人 | 每周日 02:00–04:00；后端（值班）与供应商支持邮箱 |
| 故障注入验证 | 注入 429 与超时各 3 次，降级生效，记录 `.tmp/ext/EXT-CONV-001.md` |

## 4 与条款、门禁的引用

- 条款：MX-6-29 规定外部依赖列六项（依赖名、配额窗口、限流阈值、重试与退避、熔断与半开、降级行为）；MX-G-67 核登记五项（依赖编号、配额窗口与上限、限流阈值、熔断与半开、降级行为）与注入四项（配额窗口核对、限流命中、熔断与半开、降级注入，按 MX-9-32）；本表另登记版本锁定范围、变更通知提前天数、停服窗口与联系人三项。
- 门禁：外部依赖门核登记与降级验证；证据门核配额窗口、限流命中、熔断与降级故障注入四类证据；兼容门核版本锁定。
- 验收：`TASK-MATRIX.md` 第 2.1 节「外部依赖策略」行的判定人取本表判定列。
