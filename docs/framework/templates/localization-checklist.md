# 本地化清单（localization）

版本：v1.0，2026-11-24。状态：active。
定位：本文件是一个变更或一个页面的本地化检查记录，一次检查填一份，覆盖语言清单、词条键、格式、伪本地化与缺键回退五类。
依据：`docs/framework/domains/frontend.md` 第 3.6 节与 MX-FE-54、MX-FE-55，`docs/framework/domains/product-design.md` MX-PD-29 的本地化范围，`docs/framework/templates/contract-table.md` 类 1 的本地化列。
落点：`specs/changes/<CHG-ID>/evidence.md` 的本地化节，长期清单并入 `specs/frontend/<域>/spec.md` 的文案资源节。

## 1 使用条件

新增界面、新增文案、新增语言、修改日期或数字格式任一项时必填。四项都不成立时在变更包写 `N/A：<理由>` 与重开条件。填写人取前端 owner，产品确认语言清单与默认语言，验收核对完成率与证据。

## 2 语言与时区

| 字段 | 填写内容 | 判定 |
|---|---|---|
| 支持语言 | 语言标签逐项列出，例如 `zh-CN`、`en-US` | 与产品清单不一致按缺失计 |
| 默认语言 | 一个语言标签 | 缺默认语言不得冻结 |
| 回退链 | 默认语言到基础语言到英语，逐级写清 | 缺一级按缺失计 |
| 默认时区 | IANA 时区名，例如 `Asia/Shanghai` | 写 UTC 偏移按不合格计 |
| 时区来源 | 用户设置、账号设置或产品默认三值之一 | 未写来源按缺失计 |
| 语言覆盖结论 | 每种语言的词条完成率，按已翻译除以总键数 | 只写“已完成”按缺失计 |

## 3 词条键与回退

| 检查项 | 通过条件 | 结果 |
|---|---|---|
| 键名格式 | 点分三段，段内只用小写字母、数字与下划线 | 待填 |
| 键名语义 | 一个键只对应一个语义，同一语义跨页面复用同一键 | 待填 |
| 占位符 | 占位符名与接口字段名一致，占位符数量与顺序一致 | 待填 |
| 复数分支 | 按 ICU MessageFormat 写 `one` 与 `other` 分支，分支数与语言规则一致 | 待填 |
| 其他语言键集 | 每种语言的键集合与默认语言一致，缺键数为 0 | 待填 |
| 废弃键 | 标记 `deprecated` 并写替代键，替代完成后删除 | 待填 |
| 术语表 | 术语、译法与裁定人三项齐全 | 待填 |

## 4 格式检查

| 检查项 | 通过条件 | 结果 |
|---|---|---|
| 日期 | 用 `Intl.DateTimeFormat` 构造，写 `locale` 与 `timeZone` 两项 | 待填 |
| 时间 | 12 小时制与 24 小时制按语言规则，秒与毫秒按场景取舍 | 待填 |
| 数字 | 用 `Intl.NumberFormat`，千分位与小数点随 `locale` | 待填 |
| 货币 | 写 `style` 与 `currency` 两项，币种代码用 ISO 4217 | 待填 |
| 相对时间 | 用 `Intl.RelativeTimeFormat`，`numeric` 取 `auto` | 待填 |
| 格式唯一性 | 同一页面同一类数据只用一种格式，格式来源指向契约表类 1 | 待填 |

手写拼接日期、按浏览器本地时区显示与只写一种复数分支三种做法按不合格计。格式来源在契约表类 1 的本地化列登记一次，页面不再维护第二份格式表。

## 5 伪本地化与布局

伪本地化在一轮构建内执行一次，把 ASCII 字母替换为带重音字符并把文本长度扩展 30% 至 40%。溢出、截断与换行点三项逐项检查，三项各留截图或 DOM 测量。按下表记录结果。

## 6 缺键与运行日志

缺键时界面向用户显示回退语言文本，同时上报 `i18n_missing` 计数与键名，不把原始键名显示给用户。运行日志记录键名、语言与页面路径三项，同一键重复缺失只计一次。发布前缺键数必须为 0；确实无法补齐时按产品豁免登记，写到期日与替代文案。

## 7 验收记录

| 字段 | 填写内容 |
|---|---|
| 结论 | `pass`、`partial`、`failed` 三值之一 |
| 语言覆盖 | 逐语言写完成率与未覆盖键数 |
| 未通过项 | 键名或格式项、原因与责任人 |
| 填写人 | 前端 owner 角色名与日期 |
| 判定人 | 验收角色名与日期 |
| 产品确认 | 语言清单与默认语言确认人 |

## 8 检查清单

- [ ] 默认时区用 IANA 名，时区来源已写。
- [ ] 词条键格式与语义检查通过，废弃键有替代关系。
- [ ] 占位符、复数分支与键集合逐语言一致。
- [ ] 日期、数字、货币与相对时间四类格式有结论。
- [ ] 伪本地化四档截图与三项测量齐全。
- [ ] 缺键数为 0，缺键日志字段齐全。
- [ ] 结论只取三值，语言覆盖写完成率。
