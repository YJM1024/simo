# 安全矩阵模板（security-matrix）

版本：v1.0，2026-11-25。状态：active。本模板服务 `MOXIAN.md` 第 9 章、第 10 章与该册第 6 章授权条款，`docs/framework/ROLES.md` MX-R-39，落点 `docs/framework/templates/security-matrix.md`。安全评审门的适用子集与 N/A 理由按本表登记。

## 1 用途与何时用

涉及认证、授权、文件上传、外部依赖与插件沙箱的任务，在安全评审门发起前填一次。矩阵按 ASVS L1 条款逐条登记适用性、实现位置与验证方式；不适用条款必须写 N/A 理由与批准人。插件与外部工具的复核单列一节，恶意样本不少于 8 条，覆盖崩溃、超时、资源超限与越权四类。

## 2 字段表

| 列名 | 必填 | 取值口径 |
|---|---|---|
| 条目编号 | 是 | `SEC-<域>-<三位序号>`，域内唯一 |
| ASVS 条款号 | 是 | 写章节号与条款号，例如 `V2.1.1`；引用 L1 适用子集，不整份照抄 |
| 检查项 | 是 | 一句话写被检查的行为，不写「安全加固」这类泛指 |
| 适用性 | 是 | 适用、不适用两值；不适用必须填 N/A 理由 |
| 实现位置 | 是 | 文件路径加函数名或中间件名，一行一个 |
| 验证方式 | 是 | 自动用例路径、人工步骤或工具命令，三选一并写全 |
| 证据路径 | 是 | 报告、日志或截图路径；人工步骤写记录文件 |
| N/A 理由 | 条件必填 | 适用时写「无」；不适用时写理由、批准人与有效期 |
| 严重度 | 是 | 高、中、低三档，与缺陷四级表映射 |
| 处置结论 | 是 | 通过、整改中、接受风险三值；接受风险写裁决编号 |
| 判定人 | 是 | 安全评审人；插件与工具复核另列一条 |

## 4 与条款、门禁的引用

- 条款：MX-R-39 规定安全评审人职责、插件与工具复核单列与恶意样本四类覆盖；`MOXIAN.md` 第 6 章类 10 授权策略与本表条款号互相引用。
- 门禁：安全评审门核本表齐全与 N/A 理由；证据门核验证方式与证据路径；插件市场审核门复用本表的插件复核节。
- 判定：结论三值由安全评审人签，实现者不得签本人条目的「通过」。
