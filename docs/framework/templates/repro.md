# 复现记录模板（repro）

版本：v1.0，2026-11-25。状态：active。本模板服务 `MOXIAN.md` 第 5 章 MX-5-21 与 `TASK-MATRIX.md` 第 3 节安全修复格，落点 `docs/framework/templates/repro.md`，记录文件写 `.tmp/intake/<CHG-ID>/repro.md`。

## 1 用途与何时用

缺陷修复与安全修复在受理阶段由测试角色复现后填写，一项缺陷一份，复现人不得为修复卡 owner。六项字段缺一或实际结果没有可打开的截图、命令输出时，判级门判不通过，缺陷退回提出人。复现记录只留在对话里按未复现处理。

## 2 字段表

| 列名 | 必填 | 取值口径 |
|---|---|---|
| 环境 | 是 | 操作系统、浏览器或设备、构建号与数据版本四项，逐项写版本号 |
| 版本 | 是 | 应用版本与提交号；相对当前主干时的差异提交号一并写 |
| 复现步骤 | 是 | 编号步骤，每步写一次操作与一个可观察结果，可交叉引用具体选择器 |
| 期望结果 | 是 | 一句话写应当发生什么，引用 AC 编号或契约项编号 |
| 实际结果 | 是 | 写实际观测到的值与断言，附截图路径或命令输出路径 |
| 严重级别 | 是 | 阻断、严重、一般、轻微四值之一，与 `TASK-MATRIX.md` 第 1 节缺陷四级表一致 |
| 复现结果 | 是 | 稳定复现、偶发、未复现三值；偶发写出现次数与总次数 |
| 复现人 | 是 | 角色名加日期；不得为本次修复卡 owner |
| 关联变更与任务卡 | 是 | `CHG-<域>-<NNN>` 与任务卡号 |

## 3 填写示例

| 字段 | 示例 |
|---|---|
| 环境 | Windows 11 23H2、Chrome 131.0.6778.86、构建 `mwrpos0p-d8dkh`、数据版本 v7 |

| 严重级别 | 严重 |
| 复现结果 | 稳定复现，5 次 5 次 |
| 复现人 | 测试，2026-11-25 |

## 4 与条款、门禁的引用

- 条款：MX-5-21 规定六项字段、记录路径与复现人限制；安全修复的复现角色按 `TASK-MATRIX.md` 第 1 节由未参与修复的另一域实现者执行。
- 门禁：判级门核六项齐全与实际结果可打开；矩阵缺陷修复与安全修复格的模板列写「repro 记录」，按 `MOXIAN.md` 的产物定义核对（另有 ARTIFACT 登记，不要求模板文件名）。
- 证据：复现记录路径与命令输出写进 `templates/evidence-index.md` 的「缺陷证据」组。
