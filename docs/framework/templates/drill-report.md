# 演练报告模板（drill-report）

版本：v1.0，2026-11-25。状态：active。本模板服务 `MOXIAN.md` 第 9 章与第 11 章、`domains/testing.md` MX-QA-66，落点 `docs/framework/templates/drill-report.md`。迁移演练门的证据按本表出具，原 `templates/runbook.md` 第 6 节的临时记录迁入本表后停用。

## 1 用途与何时用

数据迁移、灾备切换、生产变更与演练类任务在演练结束后当天出具，一次演练一份，连续演练按场次分行。报告未出具前迁移演练门不通过；RTO 与 RPO 实测值为空时不写「达标」。

## 2 字段表

| 列名 | 必填 | 取值口径 |
|---|---|---|
| 演练编号 | 是 | `DR-<域>-<YYYYMMDD>-<NN>` |
| 演练对象 | 是 | 系统、库或链路名，写版本与构建号 |
| 演练类型 | 是 | 备份恢复、主备切换、回滚、限流降级四值之一 |
| 计划 RTO | 是 | 目标恢复时长，写分钟数 |
| 实测 RTO | 是 | 从故障注入到服务可用的分钟数，写起止时刻 |
| 计划 RPO | 是 | 目标数据丢失窗口，写秒或分钟 |
| 实测 RPO | 是 | 最后一条已确认数据与恢复点的时间差 |
| 备份校验 | 是 | 备份文件哈希、校验命令、抽检表与行数、校验结果 |
| 切换顺序 | 是 | 编号步骤，每步写执行人、检查点与判定值 |
| 切换一致性 | 是 | 切换前后对账口径与差异行数，差异为 0 才判一致 |
| 回退条件 | 是 | 触发回退的指标、比较符与阈值，写判定人 |
| 回退实测 | 是 | 回退耗时与回退后一致性结论；未演练写 `N/A：<理由>` |
| 证据路径 | 是 | 日志、监控截图与对账输出的文件路径，逐项一行 |
| 判定人 | 是 | 演练发起角色与复核角色各一人，不得为同一次执行者 |

## 3 填写示例

| 字段 | 示例 |
|---|---|
| 演练编号 | `DR-CONV-20261125-01` |
| 演练类型 | 主备切换 |
| 计划 RTO / 实测 RTO | 5 分钟 / 4 分 12 秒，`10:00:00` 注入、`10:04:12` 恢复 |
| 计划 RPO / 实测 RPO | 30 秒 / 8 秒 |
| 备份校验 | `Get-FileHash` 哈希一致；抽检 `messages` 表 3 个分片各 1000 行，行数一致 |
| 切换一致性 | 按租户汇总行数，差异 0 行 |
| 回退条件 | 错误率超过 1% 或写 p95 超过基线 2 倍，连续 3 个窗口，判定人后端（值班） |
| 判定人 | 发起：后端；复核：验收 |

## 4 与条款、门禁的引用

- 条款：MX-QA-66 规定五组证据（备份校验、切换一致性、回退、对账、判定人）；MX-9-24 的测量口径适用于 RTO 与 RPO 的计时。
- 门禁：迁移演练门核本表字段齐全；证据门核证据路径可打开；`MOXIAN.md` 附录 B 表 B-3 登记本门的发起与复核角色。
- 附录 A：本模板落地后 `drill-report` 条目状态由「待建」改为「现行」，路径改为 `docs/framework/templates/drill-report.md`。
