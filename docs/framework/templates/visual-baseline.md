# 视觉基线模板（visual-baseline）

版本：v1.0，2026-11-25。状态：active。本模板服务 `MOXIAN.md` 第 9.2 节 MX-9-11 与第 10 章，落点 `docs/framework/templates/visual-baseline.md`，登记表与 `frontend/scripts/check-visual-baseline.mjs` 的配置同批维护。

## 1 用途与何时用

界面调整、新功能与设计交付在每个视觉出口前登记一次：哪些页面、在哪些档位、与哪份基线比、容差多少、哪些区域遮罩。改动前登记基线与档位，改动后按同一份配置复跑；基线本身变更须走契约变更单，不在评审现场改。

## 2 字段表

| 列名 | 必填 | 取值口径 |
|---|---|---|
| 基线编号 | 是 | `VB-<域>-<三位序号>`，域内唯一，删除留空号 |
| 页面与路由 | 是 | 页面名加路由路径，一页一行 |
| 档位 | 是 | 375、768、1180、1600 四档；有 1280 独立断点时加一档，写进备注 |
| 视口宽高 | 是 | 像素整数，与档位一致，例如 `375×812` |
| 截图路径 | 是 | `frontend/evidence/visual/<页面>-<档位>.png` |
| 像素差阈值 | 是 | 默认 `0`；非零须写理由与批准人 |
| 遮罩区域 | 是 | 选择器列表加遮罩原因（时间戳、随机图、动画帧）；无遮罩写「无」 |
| 重叠像素阈值 | 是 | 遮挡类改动的重叠像素默认 `0`，并写可见高度断言 |
| 采样时点 | 是 | 页面稳定后毫秒数，默认 `1000` |
| 容差来源 | 是 | 写进 `check-visual-baseline.mjs` 配置的键名，不散落在用例里 |
| 判定人 | 是 | `自动` 或 `人工:<动作>`；人工判定写角色名 |
| 复核人 | 是 | 与判定人不同的角色，界面改动由前端与设计各一人 |

## 4 与条款、门禁的引用

- 条款：MX-9-11 规定三至五个关键页面、四档档位、像素差阈值与遮罩口径；`domains/testing.md` 的证据写法按本表列名登记。
- 门禁：证据门（MX-G-38 至 MX-G-43）核截图路径与基线版本；可访问性门核档位覆盖；设计交付验收按 `TASK-MATRIX.md` 第 2.1 节判定人列签字。
- 模板列写法：矩阵界面调整与设计交付格的模板列仍写「evidence」并引用本表编号，不新增模板名。
