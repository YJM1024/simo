# 迁移计划模板（migration-plan）

版本：v0.3，2026-11-24。状态：active，随第二阶段压测补缺修订；v0.3 于同日新增第 3.1 节分片路由与第 6.1 节回退数据保全，v0.2 的内容保留。
定位：本文件是一次数据迁移的完整计划，写清范围、批次、重试、续跑、中断判定、备份、演练与回滚，缺字段的计划不得进入契约门。
依据：`docs/framework/MOXIAN.md` 第 8 章 MX-8-27、MX-8-28 与表 8-2，`docs/framework/domains/backend.md` MX-BE-23，`docs/framework/TASK-MATRIX.md` 第 3 节数据迁移行。
落点：`specs/changes/<CHG-ID>/migration-plan.md`，与 `spec.md`、`design.md`、`evidence.md` 同目录。

## 1 使用条件

计划在契约门冻结前写定，涉及删列、改类型、拆表、存量数据回填或唯一约束变更五项之一时必写。五项都不成立时在变更包写 `N/A：<理由>` 与批准人，不留空文件。计划随契约一起冻结，冻结后改批次大小或重试次数须走契约变更单。

## 2 基本信息

| 字段 | 填写内容 | 要求 |
|---|---|---|
| 变更号 | `CHG-<主域>-<NNN>` | 与变更包首部一致 |
| 迁移名称 | 一句可读的名称 | 写对象与动作，不写代号 |
| 涉及数据 | 表名、列名、行数量级 | 行数取最近一次生产备份的实测值 |
| 可逆性 | 可回滚、部分可回滚、不可回滚三值之一 | 不可回滚时写用户裁决记录编号 |
| 停机窗口 | 在线、短停或停服 | 停服写预计时长与替代入口 |
| 决定人 | 数据 owner 的角色名与任务卡卡号 | 按 `ROLES.md` MX-R-33 指派，与 `MX-5-23` 的处置决定人一致 |
| 演练环境 | 副本来源、版本、数据量 | 取最近一次生产全量备份 |

## 3 数据语义与映射

本节日志写明迁移前后的结构与字段映射，一处一行，逐行写源字段、目标字段、类型转换规则与空值处理。迁移涉及唯一约束时写历史重复值与空值的处置方式，处置方式只取保留一条并附删除清单、迁移到新字段、拒绝写入并登记例外三种，删除清单写主键范围、行数与对账口径。

### 3.1 分片路由与数据分布

涉及拆库、分表或分片键变更时填写本节，三项都不涉及写 `N/A：<理由>` 与重开条件。分片键写层级与使用条件，路由函数写函数名、输入、输出、取模基数与版本号，库标识写逻辑库名与物理连接名，全局唯一 ID 写位段划分与时钟回拨处理。字段口径与 `domains/backend.md` MX-BE-81、`templates/contract-table.md` 类 9 一致。

| 项目 | 填写内容 | 判定 |
|---|---|---|
| 分片键 | 租户标识与业务主键两级，写使用条件 | 只写租户标识按缺失计 |
| 路由函数 | 函数名、输入、输出、取模基数与版本号 | 缺版本号按缺失计 |
| 库标识 | 逻辑库名与物理连接名，写分片数量 | 与部署清单不一致按缺失计 |
| 全局唯一 ID | 位段划分、生成位置与时钟回拨处理 | 用自增主键充当全局 ID 按缺失计 |
| 跨库一致性 | 事务边界、读取方式与写入补偿三项 | 缺一项按缺失计 |
| 双写与回填 | 双写起止时点、回填顺序与逐库计数核对 | 只写全表行数按缺失计 |

## 4 批次、重试与续跑

批次与失败的处置写死在表中，执行时按表执行，不临时调整。

| 项目 | 取值 | 判定 |
|---|---|---|
| 批次大小 | 每批行数与提交方式，例如 `5000` 行一批、每批一个事务 | 未写行数或提交方式按缺失计 |
| 单批耗时上限 | 秒数，超过时告警 | 与演练实测耗时对照 |
| 重试次数 | 每批最多重试次数与退避间隔 | 未写次数按缺失计 |
| 重试失败处理 | 停批、写断点表、退出非零码 | 继续执行按违规计 |
| 续跑起点 | 从最后提交批次的下一批开始 | 按行数或时间推断按违规计 |
| 幂等要求 | 同一批重复执行不产生重复行 | 写去重键或自然键 |

## 5 中断判定与断点表

断点表逐批写一行，字段为批次号、起始主键、结束主键、处理行数、失败行数、提交时间与校验和。中断后以断点表与已提交批次判定已处理范围，断点表缺失或最后一行没有提交时间时按未处理计。无法判定已处理范围时回滚到迁移前备份并从头重跑，不按行数估算、不按时间推断、不重建索引。

## 6 备份、回滚与演练

备份写路径、时间、大小与校验和，回滚写触发条件、回滚命令、回滚后验证三处。回滚触发条件取对账不一致行数超过阈值、迁移中断且断点表不可信、唯一约束冲突未清零三类之一。演练在停止服务后的副本上执行一次，记录升级耗时、关键接口计数、health 状态与恢复后的同一组数字，四项齐全才算演练通过。

### 6.1 回退数据保全

拆库或在线迁移的回退不能只按迁移前备份恢复，切换后写入的数据必须保全或写清丢弃口径。回退写反向同步、停写时点与丢弃口径三项，三项缺一不得回退；四项都不涉及在线双写时写 `N/A：<理由>` 与批准人。

| 项目 | 填写内容 | 判定 |
|---|---|---|
| 反向同步 | 从新库按分片键回写原库的脚本、执行顺序与校验命令 | 未写脚本或校验按缺失计 |
| 停写时点 | 回退前停止写入的时间点与判定方式 | 只写「择机」按缺失计 |
| 丢弃口径 | 允许丢弃的数据范围、行数量级与批准人 | 未写批准人不得丢弃 |
| 回退窗口 | 在线迁移允许的回退时长与超期处理 | 超期后改前向修复并写裁决编号 |
| 数据核对 | 回写后按分片键分组的行数、校验和与抽样 | 只比全表行数按缺失计 |

回退执行前先停写并记录停写时点，再跑反向同步，同步完成后按分片键分组核对，核对通过才切换读取路径。反向同步失败或核对不一致时停止回退，保持新库写入并登记异常，不在数据不一致的状态下切换。

## 7 对账

对账写迁移前后的行数、关键字段分布与抽样结果。抽样按 `MOXIAN.md` MX-9-25 的样本量、抽样方法与失败判定执行，记录写该条的八项字段，`domains/testing.md` MX-QA-58 只作引用。对账不一致时停在证据门，先查差异再决定回滚。

## 8 审批与放行

生产执行前由 owner 提交、验收复核、Lead 批准，涉及停服时另由用户确认窗口。审批记录写审批人、批准时间、批准范围与停机窗口，缺任一项不得上生产。放行后把实际耗时、实际行数与对账结果回填本计划。
