# 审核事件记录模板（audit-events）

版本：v1.1，2026-11-25。状态：active。本模板服务 `MOXIAN.md` 第 8 章与第 9.2 节 MX-9-29，落点 `docs/framework/templates/audit-events.md`。插件市场与独立工具的审核流程事件按本表逐条留痕。

## 1 用途与何时用

受理、审核、驳回、申诉、复核决定五类事件发生时当场登记，一条事件一行，按时间追加，不改写历史行。事件表是插件市场审核门与申诉复核的唯一事实来源；缺少任一环节的记录时，该插件不得进入发布放行。

## 2 字段表

| 列名 | 必填 | 取值口径 |
|---|---|---|
| 事件编号 | 是 | `AE-<域>-<YYYYMMDD>-<NN>`，按登记顺序连续 |
| 事件类型 | 是 | 受理、审核、驳回、申诉、复核决定五值之一 |
| 对象 | 是 | 插件编号或工具名加版本号 |
| 操作人 | 是 | 角色名；审核人与复核人不得为同一人，申诉受理人不得为出具驳回决定的人，复核人不得为插件开发者 |
| 发生时间 | 是 | `YYYY-MM-DD HH:MM`，写时区 |
| 结论与理由 | 是 | 结论取通过、驳回、维持、改判四值之一，理由写触发条款与证据指针 |
| 证据路径 | 是 | 扫描报告、复核单、申诉材料与通知记录的文件路径 |
| 时限 | 是 | 受理 2 个工作日、驳回 1 个工作日、申诉 5 个工作日等，写到期日 |
| 通知对象与渠道 | 是 | 开发者、市场运营与安全评审人，写渠道 |
| 后续动作 | 是 | 下架、恢复上架、限期整改或归档，写执行人与完成判据 |

## 4 与条款、门禁的引用

- 条款：MX-9-29 规定扫描与审核证据六项；`MOXIAN.md` 第 8 章规定审核流程与留痕；MX-R-41 规定审核人、复核人与申诉受理人的兼任关系。
- 门禁：插件市场审核门核五类事件齐全与结论可追溯；证据门核证据路径；收口门核驳回与申诉闭环。
- 判定：审核结论由市场审核人出具，驳回决定由市场审核人出具，复核决定由复核人独立复核后出具，申诉由申诉受理人受理并记录答复时间；三类人员分离按 MX-R-41 核对，验收只签最终判定，不代出复核结论。
