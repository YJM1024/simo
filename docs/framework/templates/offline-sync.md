# 离线与弱网同步设计模板（offline-sync）

版本：v1.1，2026-11-25。状态：active。本模板服务 `MOXIAN.md` 第 6 章 MX-6-25、表 5-2「运行条件」与 `docs/framework/domains/testing.md` 第 5 节，落点 `docs/framework/templates/offline-sync.md`。契约表类 2 缓存状态列与类 4 合并规则列引用本表编号。v1.1 于 2026-11-25 把第 3 节的测量命令改为 `scripts/measure-net.mjs` 脚本口径，字段表、五档网络与合并规则不变；本模板按自身版本序列计号，与框架主版本号分列。

## 1 用途与何时用

涉及离线、弱网、缓存或断网续传的变更，在契约冻结前填一次：缓存结构、TTL、失效条件、合并规则、网络档位与判定值。设计列与契约表同批冻结；只在实现里改 TTL 或合并顺序的，按契约变更单处理。

## 2 字段表

| 列名 | 必填 | 取值口径 |
|---|---|---|
| 设计编号 | 是 | `OFF-<域>-<三位序号>`，域内唯一 |
| 缓存对象 | 是 | 实体名与作用范围（列表、详情、草稿），一对象一行 |
| 存储结构 | 是 | 库名、表名与键格式，写版本号；键格式写成 `键名:取值` |
| 缓存版本 | 是 | 结构版本号与升级动作，版本不一致时的清空或迁移策略 |
| TTL | 是 | 时长与单位，写起算时点（写入时、读取时） |
| 失效条件 | 是 | 版本变化、用户退出、显式刷新与服务端失效推送四类，逐条写 |
| 离线时长上限 | 是 | 允许离线的小时数，超限后的动作 |
| 合并规则 | 是 | 去重键、优先级、冲突解决与重放顺序四项，与契约表类 4 合并规则列一致 |
| 网络档位 | 是 | 可用、2G、3G、4G、断网五档，写带宽、时延与丢包率参数 |
| 判定值 | 是 | 每档的判定值，例如首屏可用秒数、重连成功率；三档参数到五档条件的映射写 `domains/testing.md` 第 5.2 节 |
| 测量命令 | 是 | 复跑命令与样本量；无脚本时写人工步骤与记录格式 |
| 判定人 | 是 | 离线收敛结论由测试判定，前端复核 |

## 3 填写示例

| 字段 | 示例 |
|---|---|
| 缓存对象 | 会话列表与消息详情 |
| 存储结构 | IndexedDB `moxian`，`sessions:{tenantId}`，版本 3 |
| TTL | 24 小时，从写入时起算 |
| 失效条件 | 结构版本变化清空；用户退出清空；下拉刷新覆盖；服务端 `session.invalidated` 推送删除单条 |
| 合并规则 | 去重键 `(sessionId, seq)`；服务端优先；整条覆盖；按 `seq` 升序重放 |
| 网络档位 | 4G：10 Mbps / 50 ms / 0.1%；3G：1.5 Mbps / 300 ms / 0.5%；2G：250 kbps / 800 ms / 2%；断网：0 |
| 判定值 | 4G 首屏 ≤1s；3G ≤3s；2G 显示骨架不超 5s；断网可读缓存列表并在恢复后 10s 内同步 |
| 测量命令 | `node scripts/measure-net.mjs --mode latency --target 127.0.0.1:9000 --count 20 --threshold p95=<该档判定毫秒> --out docs/testing/measure-net-<TC 编号>-<档位>-latency-<YYYYMMDD-HHmm>.json`；丢包用 `--mode loss --count 50 --threshold loss=<该档上限>`，吞吐用 `--mode bandwidth --size 65536 --timeout 15000 --threshold mbps>=<约定值>`；9000 为注入代理监听端口示例，档位与判定值按 `testing.md` 5.2 节表取值，不再人工按 DevTools Network 节流记录 |

## 4 与条款、门禁的引用

- 条款：MX-6-25 规定缓存状态四项与合并规则四项；表 5-2「运行条件」六项与本表一一对应。
- 门禁：弱网与离线门核六档参数、TTL、失效与合并规则齐全；证据门核三档到五档证据写法；契约门核类 2 与类 4 引用本表编号。
- 验收：`TASK-MATRIX.md` 第 2.1 节「离线收敛」行的判定人取本表「判定人」列。
