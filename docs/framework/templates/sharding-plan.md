# 分片与重分片方案模板（sharding-plan）

版本：v1.0，2026-11-25。状态：active。本模板服务 `MOXIAN.md` 第 6 章 MX-6-26、契约表类 9 与 `docs/framework/templates/migration-plan.md` 第 3.1 节，落点 `docs/framework/templates/sharding-plan.md`。迁移演练门的跨分片一致性证据按本表出具。

## 1 用途与何时用

新增分片、调整分片键、改路由函数或做跨库迁移时，在契约冻结前填一次，迁移前复核一次。跨分片查询一致性、路由命中与重分片核对三项没有证据时，迁移演练门不通过；重分片方案不得在演练前修改路由函数。

## 2 字段表

| 列名 | 必填 | 取值口径 |
|---|---|---|
| 方案编号 | 是 | `SHD-<域>-<三位序号>`，域内唯一 |
| 数据对象 | 是 | 表名或集合名，一对象一行 |
| 分片键 | 是 | 全部层级与使用条件，只写租户标识的按缺失计 |
| 路由函数与版本 | 是 | 函数名、输入、输出与取模基数，写 `routeV1` 这类版本号 |
| 库标识 | 是 | 逻辑库名与物理连接名，不写明文密码 |
| 跨库事务边界 | 是 | 禁止跨库事务时的替代路径（outbox 加补偿），写补偿任务名 |
| 跨分片查询一致性 | 是 | 三条：读取方式（接口聚合或双写读）、允许的陈旧窗口、对账口径 |
| 重分片步骤 | 是 | 编号步骤，每步写执行人、检查点与判定值 |
| 回退点 | 是 | 可回退的步骤号与回退后校验命令 |
| 核对样本 | 是 | 抽样键范围、样本量与判定人；样本不得只取单分片 |
| 判定人 | 是 | 一致性结论由后端判定，测试复核，均不得为本次重分片执行者 |

## 3 填写示例

| 字段 | 示例 |
|---|---|
| 数据对象 | `messages` 表 |
| 分片键 | 租户标识加会话 ID 两级 |
| 路由函数与版本 | `routeV1(tenantId)` 取模 8，输出库序号；旧版本保留 30 天 |
| 跨库事务边界 | 禁止跨库事务；写入走 outbox `message_outbox`，补偿任务 `message_repair` |
| 跨分片查询一致性 | 读取走接口聚合；允许陈旧 5 秒；按租户汇总行数与校验和对账 |
| 重分片步骤 | 1 双写新库，2 按分片比对，3 切读，4 停双写，5 删旧分片；每步差异为 0 才继续 |
| 回退点 | 第 3 步前可回退；回退命令 `scripts/sharding/rollback.mjs --to=v1` |
| 核对样本 | 每个新分片抽 1000 行，旧库同键比对，判定人后端 |

## 4 与条款、门禁的引用

- 条款：MX-6-26 规定分片键、路由函数、库标识、全局 ID 与跨库一致性五项；契约表类 9 的列与本表前七行对齐。
- 门禁：迁移演练门核重分片步骤、回退点与核对样本；证据门核跨分片查询一致性、路由命中与重分片核对三项证据；契约门核类 9 引用。
- 迁移：`templates/migration-plan.md` 第 3.1 节引用本表编号，不重复列分片字段。
