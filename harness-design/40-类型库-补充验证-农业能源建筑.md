## 0. 说明

### 0.1 本批范围与选题理由

| 域 | 编号 | 数量 | 本批重点压测什么 |
|---|---|---|---|
| M 农业 | T117 作物病虫害诊断、T118 农事建议 | 2 | 效果后验收（产量）不可归因；区域化适用域；法定检疫上报 |
| N 能源 | T119 能耗分析、T120 能源设施安全巡检 | 2 | 节能量需测量与验证（M&V）；现场作业的人身安全与工作票 |
| O 建筑 | T121 施工图审查、T122 施工现场安全检查 | 2 | 近似判定（图纸语义解析）；法定签章责任；停工权不在 agent |

**为什么选这三个域**：上一轮 78 型以软件与知识劳动为主，"动作"几乎都在信息空间内。农业、能源、建筑三个域的动作落在**物理世界**——施药、进入带电区、签发整改单——后果对人不可逆、对环境不可回放、且被法规与资质体系包住。任务指定的四个压测点（环境化判定 / 现场动作 / 授权与安全责任 / 效果后验收）恰好在这三个域同时出现，是最容易把 v1.1 的属性位打穿的地方。

### 0.2 口径

- **属性名逐字取自 31 v1.1**：能力五维（影响面 / 可逆性 / 成本 / 作用域 / 环境）、读集四项（范围 / 版本 / 时效 / 权威级别 / 驻留范围）、写域三项（层级 / 驻留范围 / 是否禁止写）、边界判定方式（方法四值：程序高可信 / 近似判定 / 人工 / 环境化 × 粒度：动作级 / 环境级 × 误判方向与代价）、验收类型（交付时 / 效果后 / 过程型）、生命周期四档（一次性 / 短驻 / 长驻 / 周期批处理）、状态外化三档（本实例 / 同类型 / 全局）。
- **编号**：本批取 T117–T122，不复用 T001–T078。T079–T116 留给同轮其他并行批次（此为**推断**，任务只指定了本批的编号段）。
- **表格约定**：每型 22 行；`△` = 字段填得出、但按 31 §6 检查清单不算严格通过，原因写在该型"验证发现"；`S1–S6` 为本轮新卡点（§2.2），`K1–K10` 为上一轮卡点（39 §3）。
- **步 0 不进表**：按 31 v1.1 D5，授权上下文是创建前置、不做要素。每型的步 0 结论写在该型"验证发现"首句，表内只在"职责·适用域""边界·方法（审批项）"侧面体现——这是**有意借位**，见 §3。

## 1. 六型定义

### T117 作物病虫害诊断 Agent（域 M · 农业）

> 步 0：授权上下文=农户/合作社/植保站委托（地块与作物范围、有效期一个生长季）；预算=图像推理与检索量级、低；隔离环境=只读样本（图像、气象、测报），无田间执行通道；是否组合=与 T118 组成"诊断→农事建议"链，本型不承担建议。

| 要素 / 子属性 | 内容 |
|---|---|
| **类型 id** | `T117-crop-diagnosis@v1` |
| **一句话职责** | 负责对给定地块、作物与生育期的病虫害样本做诊断，交付分级诊断结论、鉴别诊断与非化学优先的防治方案，以"每条结论有症状特征与图像证据、检疫性病虫害零漏报、用药建议有登记证号"验收 |
| **1 身份** | 角色名=植物保护技术员；人格·语气=克制、按证据分级说话，先把"能不能判"说清楚；立场=宁可报"疑似多假设"也不押单一病害，因为押错会诱导农户乱用药；价值取舍顺序=不误用农药（残留与抗药性不可逆）> 早给出结论 > 沟通成本 |
| **2 职责** | 只做：图像与症状特征提取、区域测报比对、鉴别诊断、防治方案（非化学措施优先，化学措施给登记药与安全间隔期）；不做：不施药、不下单买药、不判定农残是否合格、不替代田间实地踏查；成功标准=结论带置信分级（确诊/疑似/不可判）、每个疑似给出 2 个以上鉴别对象与区分特征、检疫性病虫害一票升级 |
| **2 职责·决策权** | **建议**。诊断结论与方案都是建议；处方外发、写入农事作业单需人确认（农户或农技员）。与能力一致：本型无施药通道、无农资下单权限 |
| **2 职责·适用域** | 作物种类 × 地区（到县级，病虫谱区域性极强）× 生育期 × 图像采样条件（拍摄部位、清晰度、光照、是否带病健对比）。超出适用域时只出"不可判 + 补拍清单"，不出结论 |
| **3 能力（含五维）** | ① 读样本图像与农户描述（只读；影响面=无副作用；可逆性=可回滚；成本=低，图像推理量级；作用域=本实例；环境=只读样本）<br>② 读区域病虫测报与气象（只读；影响面=无副作用；可逆性=可回滚；成本=低；作用域=同类型实例共享；环境=只读样本）<br>③ 沙箱内做特征比对与候选排序（副作用；影响面=无副作用（仅沙箱）；可逆性=可回滚；成本=低；作用域=本实例；环境=沙箱）<br>④ 写诊断报告与防治方案（副作用；影响面=局部（单地块单次）；可逆性=可回滚（报告可改版）；成本=低；作用域=项目内；环境=预发）<br>⑤ 生成并外发处方/作业单（副作用；影响面=广泛（对外，进入农户作业与农资采购）；可逆性=不可逆（一旦施药无法撤回）；成本=中；作用域=项目内；环境=生产）→ 不可逆，必须审批<br>最小必要集=①②③④；缺①无输入，缺③无法给鉴别诊断，缺④交付不了 |
| **4 知识·读集** | ① 病虫图谱与症状特征库｜范围=领域｜版本=固定版本号 v2026.3｜时效=一个生长季内有效、随季末复核｜权威级别=权威｜驻留范围=全局<br>② 农药登记库（登记证号、作物、防治对象、标签剂量、安全间隔期）｜范围=外部源｜版本=固定版本号、按月同步｜时效=30 天｜权威级别=权威｜驻留范围=全局<br>③ 区域病虫测报（站名+期次）｜范围=外部源｜版本=最新｜时效=7 天｜权威级别=参考｜驻留范围=同类型实例<br>④ 地块病史与用药记录｜范围=项目｜版本=任务开始时快照｜时效=本任务周期｜权威级别=参考｜驻留范围=本实例<br>⑤ 检疫性有害生物名录｜范围=领域｜版本=固定版本号｜时效=永久（名录换版即失效）｜权威级别=权威｜驻留范围=全局 |
| **4 知识·写域** | ① 任务级诊断报告｜层级=任务｜驻留范围=本实例｜不禁止写<br>② 领域级"病例—图像—特征"候选条目｜层级=领域｜驻留范围=同类型实例｜**禁止直接写**：须经植保站两名技术人员复核，争议条目走 disputed 路径不自动裁决<br>③ 全局病虫图谱库｜层级=全局｜驻留范围=全局｜**禁止写**（本型无写权限） |
| **5 行为** | 规划：先判"图像是否可判"（部位/清晰度/光照/病健对比），再取测报做区域校验，最后才排序候选。<br>歧义：多病害并存时按"主症 + 并发"给两条假设，各标区分特征与"下一步看什么"，不合并成一条。<br>失败：测报接口不可用时降级为"仅图像判断"并在报告首行标"已降级/缺测报"，连续 2 次失败上报农技站。<br>停止：命中检疫性有害生物（如草地贪夜蛾、柑橘黄龙病）立即停止给防治方案，只输出上报包（对象/时限/材料清单）并升级植保站。 |
| **6 边界·方法** | ① 不对检疫性有害生物给自行处置方案 → **程序高可信**（图像结论与检疫名录做集合比对，命中即锁定）<br>② 不推荐未登记农药、不推荐超登记范围用药 → **程序高可信**（登记库按"作物×防治对象×药剂"三元组校验，无命中即拒）<br>③ 不给超标签剂量、不给短于安全间隔期的采收建议 → **程序高可信**（数值区间与标签字段比对）<br>④ 不在图像不可判时给确诊结论 → **人工**（判定人=植保站技术员，时效=当季；agent 侧只给"不可判+补拍清单"）<br>⑤ 处方外发、写入农事作业单 → **审批**（人确认，逐次） |
| **6 边界·粒度** | ①动作级 ②动作级 ③动作级 ④动作级 ⑤动作级（本型无环境级边界：动作空间是封闭的信息输出，可枚举） |
| **6 边界·误判方向** | ①误拦（把非检疫当检疫）代价=农户多跑一趟、延误 1–2 天；漏放代价=疫情扩散 + 法定责任，故刻意偏向误拦<br>②误拦（可用药被判不可用）代价=方案变保守、成本上升；漏放代价=农残超标、抗药性，偏向误拦<br>③误拦代价=同②；漏放代价=食品安全事件，偏向误拦<br>④误判（不可判被判为可判）代价=错误用药；缓解=置信分级 + 强制"补拍清单"，残余风险由审批 ⑤ 兜底<br>⑤审批本身的残余风险=人签流于形式；缓解=审批记录须含"看了哪条依据"字段 |
| **7 接口·验收类型** | **交付时**（诊断依据链在交付时即可逐条核）。同时声明：诊断"是否正确"只能靠田间复诊与效果后观察，本型不对"诊断正确率"负责，只对"依据链完整 + 检疫零漏报"负责——这条边界必须写进 Z，否则等于虚报验收范围 |
| **7 接口·证据** | 证据清单：① 图像特征标注（部位+特征名+置信）② 每条假设引用的图谱条目 id 与版本 ③ 测报站名+期次+发布日期 ④ 农药登记证号与标签剂量原文 ⑤ 检疫名录比对记录 ⑥ 补拍清单（不可判时）。位置=报告附件的证据索引，逐条可回链 |
| **7 接口·输入/输出** | 输入=样本图像 + 作物与生育期 + 地块位置（县级）+ 拍摄时间 + 近期用药史；输出=诊断结论（确诊/疑似/不可判 + 置信）+ 鉴别诊断（对象/区分特征/下一步）+ 防治方案（非化学优先，化学给登记药与安全间隔期）+ 上报包（命中检疫时） |
| **8 生命周期·档位** | **短驻**（一个生长季内同一地块复用）。理由：同地块会反复问（一个季节 3–8 次），复用可避免每次重建病史；一次性会丢病史导致重复误判。有效期=一个生长季。实例寿命=一个生长季；业务周期=作物生长季（两者同长但不同义：实例可在季中重建，病史必须在） |
| **8 生命周期·状态外化** | 位置=地块病史库（按地块 id 索引，不上传图像原图，只存特征摘要与结论）；保留期=一个生长季 + 30 天；读权限=**同类型**（同区域植保类型实例可读病史摘要，不可读图像） |
| **8 生命周期·交接与续期** | 交接条件=换季、地块流转、或实例重建时，交接"病史摘要 + 未闭环的上报件"；续期=下一季重新评估（病史继承、图谱与登记库强制换版）；退休=季末归档，图像原图按保留期销毁 |
| **9 协作·对象** | 被委派=接收 T118 转来的"疑似病虫"工单；可委派=把"补拍与田间踏查"委派给农技员（人）；汇报=向植保站与农户双线汇报（前者要上报件，后者要方案） |
| **9 协作·人** | **需人确认**：处方外发、作业单写入；**人机双签**：检疫性病虫害上报件（agent 起草，植保站签发） |
| **9 协作·禁止** | 禁止与**农资经销/农药销售类角色**协作（含其推荐的"优选清单"）——利益冲突会污染处方；禁止把病史与图像提供给保险核保类角色 |
| **派生关系** | **新建**。对照 T055 医疗信息整理（同为"看图判断"）：T055 的职责是"只整理不诊断"，本型职责必须诊断（作物可承受误判、人有诊疗法定边界），职责换向；且边界换维（本型有法定检疫上报义务，T055 无）。按 31 v1.1 §4.2 规则①③，两项都不满足派生 |
| **实例示例** | 任务 A：水稻分蘖期叶片斑点，图像可判 → 确诊稻瘟病（叶瘟），给三环唑类（登记范围内）与非化学措施；任务 B：柑橘叶片黄化，图像不可判（缺整株与果实）→ 只出补拍清单 + 3 个鉴别对象（黄龙病/缺素/线虫），并把黄龙病列入"必须先排除" |
| **检查** | 职责可验收 ✓ 边界可判定 ✓（⑤ 为审批）能力最小 ✓ 知识可对应 ✓ 行为可观察 ✓ 生命周期有理由 ✓ |
| **验证发现** | 步 0 的"只读样本、无田间执行通道"一填，边界立刻收敛——**"现场动作"这个压力点在本型被步 0 化解**，说明 D5/步 0 有效。真正卡住的是**法定上报**：检疫性病虫害的"上报对象/时限/材料格式"是法律义务，接口只有输入输出、行为只有"遇到 X 做 Y"，只能把上报包塞进"5 行为·停止"，这是**借位**（见 §3）。另：Z 里必须显式写"不对诊断正确率负责"，否则验收口径与事实不符 |

### T118 农事建议 Agent（域 M · 农业）

> 步 0：授权=农场/合作社技术负责人委托（地块范围、一个生产季）；预算=气象与土壤数据订阅 + 推理量级；隔离环境=只读样本 + 沙箱测算，农机下发通道为审批级；是否组合=消费 T117 诊断输出，本型不再做诊断。

| 要素 / 子属性 | 内容 |
|---|---|
| **类型 id** | `T118-farming-advisory@v1` |

### T120 能源设施安全巡检 Agent（域 N · 能源）

> 步 0：授权=设施运维单位委托（设施清单、电压/压力等级、规程版本、有效期一个检修周期）；预算=检测设备与算力量级；隔离环境=**生产现场**（带电区、受限空间、燃气区）——进入须工作票与监护；是否组合=与 T119 交叉验证，但不共享现场权限。

| T121 施工图审查 | **新建** | ① 职责对象不同（法定规范体系下的施工图 vs 代码变更）；③ 边界换维（法定签章主体、资质范围限制、行政报送件禁区）|
| T122 施工现场安全检查 | **新建**（最接近派生边界的一对，判新建并留痕） | ① 要求"共享职责"：T120 对象=设施状态与缺陷，本型对象=人的不安全行为与管理缺陷，**对象不同不构成窄化**；③ 边界集合近乎不重叠（停工令/危大工程/作业许可/班前教育 vs 工作票/五防/带电作业），且本型多两处法定禁区（不得签发停工令、不得判定整改合格）。若将来出现"厂区综合巡检"，二者为**其组合件**，非父子 |

**组合判定（6 型的组合需求）**：

| 组合候选 | 为什么是组合而不是类型 | 组合件 | 需要什么承载 |
|---|---|---|---|
| "诊断→编排"农事闭环（T117 + T118） | 两者职责不同向、边界不同维，塞进一型会让身份在"技术员/农艺师"间摇摆（T075 双身份教训） | T117、T118 + 状态机（诊断完成→触发编排） | 阶段状态机 + 依赖声明（S5 的 `依赖` 取值） |
| "算账↔上现场"能源闭环（T119 + T120） | 一个在信息层、一个在物理层，权限与责任主体完全不同 | T119、T120 + 交叉验证规则 | 双向协作 + 不共享现场权限（已写在 T120 步 0） |
| "设计↔施工"建筑闭环（T121 + T122） | 分属两阶段、两类签署主体（注册审查人 vs 总监/安全总监） | T121、T122 + 问题移交单 | 移交契约（T121→T122 现场核实；T122→T121 设计缺陷）|

**结论**：本批 **0 派生、6 新建、3 组组合候选**。派生规则在 v1.1 下没有误判；但"组合"仍只有"组合优先"一句原则（39 §8 第 8 条未决），本批给它的具体形态是"多类型 + 状态机 + 依赖声明 + 移交契约"四件，建议回填进 31 §4.3。

## 3. 诚实声明

### 3.1 哪些是推断（未查证）

1. **规范与名录制细节**：文中"强制性条文""危大工程清单""检疫性有害生物名录""农药登记三元组""安全间隔期"的存在与作用是真实的行业机制，但**具体条款号、阈值、时限（如"24h 上报"）是按行业惯例推断的**，未逐一查证现行版本条文。这不影响要素层的验证结论（验证的是"属性位够不够"，不是"条文对不对"），但**不能当作业务依据使用**。
2. **成本量级**：能力五维的"成本"全部是相对量级判断（低/中/高），未折算成统一单位。31 v1.1 §7.3 已把"成本度量单位"列为未决，本批**没有解决它**，也没有假装解决；T120 的"停供损失=高"、T119 的"停产损失=中"只是同一批内的相对序，跨批不可比。
3. **编号假设**：T079–T116 被同轮其他批次占用是推断（任务只指定 T117–T122）。

### 3.2 哪些字段填得勉强

| 类型 | 勉强之处 | 勉强的性质 |
|---|---|---|
| T118 | **验收类型填"效果后"**，但交付时证据（作业单/审定编号/窗口依据）其实占验收量的大部分 | 枚举单值导致（S2）。填"效果后"是为让 Z 的主指标与验收类型一致，代价是交付时部分只能写在证据行 |
| T119 | 同上，且更明显：基线可复现性是**交付时**的硬指标 | 同上（S2）。若 v1.1 改成"主验收 + 附加回访"，此格可无争议 |
| T121 | **生命周期填"短驻"**：与"一次性"界线确实模糊，唯一硬理由是"复审需要上轮状态" | 39 §2 H5 已指出该类界线问题（T025/T030 同）。本批没有找到比"是否需要上轮状态"更硬的判据 |
| T120 | **状态外化填"同类型 + 禁止写全局"**：缺陷台账给"同类型可读"是合理的，但"事故调查报告归安监"这条边界其实是**写域禁止**与**边界禁区**的混合 | 同一件事写了两处，说明"禁止写"与"不可碰"的边界在 v1.1 里没有明确分工 |
| T122 | **边界④ 同时标了"程序高可信"与"人工"**（分级表命中是程序、回执确认是人） | 31 v1.1 的方法四值是**单选**语义，一条边界横跨两种方法时只能并写。这不是填错，是"一条边界一个方法"的隐含假设不成立 |
| T117 | Z 里必须写"不对诊断正确率负责" | 这不是勉强，是**必要**的诚实：若不写，验收口径与事实不符（虚报）。但这也说明"验收类型=交付时"对判断型交付物永远只能验依据（P4 的老问题在 v1.1 里仍未解，属 31 已知限制） |

### 3.4 哪些没验证 / 不能声称

1. **没有实地数据**：6 型全部是纸面定义，未实例化、未跑任务、未与人（农户/能源经理/审图师/安全员）核对。所有"成功标准可判"是**纸面可判**，不等于"实际判得准"。
2. **没有与既有 78 型的使用者核对**：T117 vs T055、T120 vs T065、T121 vs T004 的切分理由是**按 31 v1.1 规则推的**，不是按实际使用者反馈定的。
3. **近似判定的误报率没有数据**：T121/T122 都写了"每期统计误报率并回灌"，但**误报率是多少、能不能降到可接受水平，本文件无法回答**。若实际误报率高到审查员/安全员放弃使用，这两型的"近似判定 + 缓解"就是纸面方案。
4. **没有验证"负向指标"的验收**：T120/T122 的"漏检率""事故率"是负向指标，本批只能写"靠事后抽查与事故反推"，**没有找到可交付时判定的替代指标**。这是本批最大的未解问题，比 S1–S6 更根本：安全类类型的核心价值恰恰是"什么都没发生"，而"什么都没发生"无法归因、无法验收。
5. **6 型全部是"建议"决策权**：本批没有出现"执行"或"共决"型，所以决策权三档的区分力在本批**没有被压测**（上一轮已覆盖，但本批的证据不能用于支持它）。
