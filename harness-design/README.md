# harness-design · 通用智能体 harness 系统设计

> 本目录是一条独立的**设计文档线**：从「以记忆为中心的 harness 运行时」走到「智能体类型系统与通用 Agent 框架」。
> 与同工作区 `../design/` 的关系：`design/` 是司墨（simo）产品项目的设计目录；本目录是**这条通用 harness 设计线**自己的家。本目录文档引用司墨既有设计资产时，用 `../design/` 前缀（如 [12-记忆模型-候选稿](../design/12-记忆模型-候选稿.md)）。

## 一、这条线在回答什么

这条线回答四个逐层收窄的技术设计问题，文件按这四个层次组织。

第一层是元框架，回答"任何智能体框架都必须提供哪些原语，才能把智能体跑起来"。对应 51 与 52，不含任何具体组织方式。

第二层是类型化框架，回答"以类型和实例为组织轴时，框架长什么样"。对应 26、29、31、33、34、45，这是整条线的主体。

第三层是材料与验证，回答"这套设计对真实世界的类型够不够用"。对应 35 到 42、46 到 50、53、56，是可复算的样本与结论。

第四层是治理与状态，回答"做过哪些裁决、现在到哪一步"。对应 43、44、49、54、55 与 `dp/`，记录决策与进度。
