# FE-004 · 首次使用与空态（Spec）

状态：approved（Lead 直接执行）
Owner：前端 `memory-researcher`

## 目标
第一次打开、无会话、无消息、无任务、无交付物时，页面仍然清楚、可行动，不是空白或假数据。

## 需求

| ID | 级别 | 需求 |
|---|---|---|
| R1 | MUST | 首次打开：无会话/空主会话时展示引导（能做什么 + 一个明确动作） |
| R2 | MUST | 空消息：提示开始对话，输入区可用；不显示"加载中"假状态 |
| R3 | MUST | 空右栏：目标/输入/执行会话/交付物分别有结构化空态 |
| R4 | MUST | 空工作台：显示真实 0 与说明，不显示假图表 |
| R5 | MUST | 加载/错误/空三态用统一组件；错误可重试 |
| R6 | SHOULD | 首次使用不自动产生测试消息/测试交付物 |

## 非目标

- 不造示例消息/任务/交付物；
- 不做首次使用引导的多步流程；
- 不新增页面/导航；
- 不改后端数据语义。

## 验收

| ID | 场景 | 期望 | 证据 |
|---|---|---|---|
| A1 | 新库/清空会话 | 首屏有引导+明确动作；无假数据 | 截图/DOM |
| A2 | 空消息/空右栏 | 输入可用；右栏四节结构化空态 | 截图 |
| A3 | 空工作台 | 显示真实 0/说明，不画假图 | 截图/API |
| A4 | 加载/错误 | 统一三态；错误可重试；1600/1180/375 无溢出 | 截图/console |
