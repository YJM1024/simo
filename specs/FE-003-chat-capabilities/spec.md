# FE-003 · 会话能力 + 消息/任务/交付物结合（Spec）

状态：approved（Lead 直接执行）
Owner：前端 `memory-researcher`；后端配合 `kernel-builder`；验收 `schema-drafter`

## 目标
把"对话"从消息列表升级为可操作的工作面：会话可管理、消息与任务/交付物关联、交付物只展示用户要的产物。

## 需求

| ID | 级别 | 需求 |
|---|---|---|
| R1 | MUST | 会话搜索：按标题/消息内容过滤，空结果有提示 |
| R2 | MUST | 归档/恢复：归档会话只读；恢复后回列表；不显示置顶/重命名以外的多余动作 |
| R3 | MUST | 消息与任务关联：任务开始时/结束时在消息流有对应消息；任务行可定位到消息/交付物 |
| R4 | MUST | 右栏「执行会话」只展示与会话相关的异步任务，状态三组；空组结构化空态 |
| R5 | MUST | **交付物只展示用户要的产物**：报告/文档/表格/文件；排除内部 attempt/report/log/checkpoint 等过程文件 |
| R6 | MUST | 无用户交付物时显示「暂无交付物」，不得用内部文件填充 |
| R7 | MUST | 交付物可打开/预览；失败有错误提示 |
| R8 | MUST | 卡片/确认回执与任务/交付物状态一致；不出现孤立状态 |

## 验收

| ID | 场景 | 期望 |
|---|---|---|
| A1 | 搜索会话 | 过滤正确、清空恢复、空结果提示 |
| A2 | 归档/恢复 | 归档只读、恢复可见、刷新保持 |
| A3 | 任务开始/结束 | 消息流出现且只出现对应消息；任务行可定位 |
| A4 | 交付物列表 | 只有用户要求产物；内部文件不出现；空态正确 |
| A5 | 打开交付物 | 可预览/下载；失败提示 |
| A6 | 三档 1600/1180/375 | 无溢出、视觉不回退 |

## 约束
- 交付物分类在后端/契约层做，不在前端用文件名硬过滤；
- 页面仍只组合组件，禁止定制 CSS；
- 不恢复任务/智能体/团队/记忆导航。
