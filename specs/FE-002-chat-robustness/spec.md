# FE-002 · 对话稳定性（Spec）

状态：draft → approved（Lead 直接批准执行）
Owner：前端 `memory-researcher`；验收 `schema-drafter`

## 背景
FE-001 已视觉验收并部署 8787。剩余真实边界未覆盖：断线、发送失败、流式中断、三态、卡片幂等。

## 目标
真实 8787 下稳定：断线可恢复、失败可重试、流式不重复、状态不假空、卡片提交幂等。

## 非目标
P1 体验优化（滚动到最新、消息复制、空态引导）、P2 右栏/工作台、P3 画廊/Storybook。

## 需求

| ID | 级别 | 需求 |
|---|---|---|
| R1 | MUST | WS 断开显示"重连中"；恢复后"已连接"，补拉消息、去重、不丢 |
| R2 | MUST | 发送失败保留输入并提示；可重试；不产生半条本地消息 |
| R3 | MUST | 流式可停止；停止后不继续追加；刷新后状态正确；无重复文本 |
| R4 | MUST | 会话/消息/右栏/工作台统一空、加载、错误三态；不静默显示 0 |
| R5 | MUST | 卡片提交失败有提示、可重试；重复提交幂等；成功后状态回写 |
| R6 | MUST | console error 0；tsc 0；build 通过 |

## 验收

| ID | 场景 | 期望 |
|---|---|---|
| A1 | 停 8787，再启动 | 状态重连中→已连接；消息补拉且无重复 |
| A2 | 模拟发送失败 | 输入保留；提示原因；重试成功 |
| A3 | 流式进行中停止 | 文本停止增长；不重复；状态可继续发送 |
| A4 | 接口失败/无数据 | 显示错误/空态，不显示假 0 |
| A5 | 卡片连续提交两次 | 第二次幂等；状态一致；有回执 |
| A6 | 1600/1180/375 | 无溢出/裁切；视觉不回退 |

## 约束
- 不改后端领域语义（如需后端幂等，单列 B 任务）；
- 不引入新 UI 库；页面不写定制 CSS；
- 不使用 DPR1 截图作为验收证据。
