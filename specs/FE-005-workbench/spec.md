# FE-005 · 工作台（Spec）

状态：approved（Lead 直接执行）
Owner：前端 `memory-researcher`

## 目标
工作台是"用量与最近活动"的真实视图，不是空壳；数据来自 API，空/错误态清楚。

## 需求

| ID | 级别 | 需求 |
|---|---|---|
| R1 | MUST | 用量卡：Token、会话、任务取真实 totals；加载/错误/0 区分 |
| R2 | MUST | 每日消息/用量图表：真实 buckets；无数据不画假柱 |
| R3 | MUST | 最近活动：真实会话，点击进入对话 |
| R4 | MUST | 交付物入口：仅用户交付物，可查看 |
| R5 | MUST | 空/加载/错误三态统一；错误可重试 |
| R6 | SHOULD | 与对话页共享外壳/组件，不复制布局 |

## 非目标

- 不做实时大屏/告警/导出；
- 不新增指标口径（以产品指标文档为准）；
- 不复制对话页布局；
- 不改后端 stats 语义（缺口另立 spec）。

## 验收

| ID | 场景 | 期望 | 证据 |
|---|---|---|---|
| A1 | 真实数据 | 用量/每日/最近活动与 `/api/stats` 一致 | API 对照/截图 |
| A2 | 空库/0 数据 | 真实 0 + 说明；不画假柱/假数 | 截图/API |
| A3 | 接口失败 | 错误可重试；不显示假 0 | 截图/网络 |
| A4 | 三档 | 1600/1180/375 无溢出；交付物入口可用 | 截图 |
