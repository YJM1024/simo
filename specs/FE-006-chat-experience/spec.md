# FE-006 · 对话体验（P1）

状态：approved（Lead 决策）
Owner：前端 `memory-researcher`；验收 `schema-drafter`

## 需求

| ID | 级别 | 需求 |
|---|---|---|
| R1 | MUST | 消息区不在底部时显示「回到底部」按钮；点击滚到底并清未读 |
| R2 | MUST | 用户上滚时新消息不强制拉底；显示新消息提示/未读计数 |
| R3 | MUST | 消息支持复制；代码块等宽、可横向滚动、不撑破卡片 |
| R4 | MUST | 会话切换后：首次进入回到底部；同一会话返回保留上次位置 |
| R5 | MUST | 空消息/首次使用显示引导与一个明确动作；不显示假加载 |
| R6 | MUST | 发送失败保留输入、可重试、有可读错误文案 |
| R7 | MUST | 375 下按钮不遮消息、不横向溢出 |
| R8 | MUST | 视觉不回退，DPR2 1600/1180/375；console 0 |

## 验收

- 上滚→新消息→提示计数；点回底→清零；
- 切换会话/返回行为正确；
- 复制内容与消息一致；长代码块不破布局；
- 失败重试成功；
- 三档截图 + 交互实测；交视觉签字。
