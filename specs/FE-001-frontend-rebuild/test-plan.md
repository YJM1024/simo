## 3. 交互测试

| 用例 | 步骤 | 期望 |
|---|---|---|
| 会话切换 | 点击两个会话 | 消息替换、滚动到底、无残留 |
| 新建草稿 | 点新建 → 发首条消息 | 草稿替换为真实会话；刷新不保留空草稿 |
| 双击重命名 | 双击 → 输入 → Enter/Esc/失焦 | 保存/取消/保存；失败保留原值 |
| 发送流式 | 发送 → 观察流式 | 文本逐步增长、无重复、结束 done |
| 断线恢复 | 停服务/断 WS → 重启 | 显示重连中→已连接；消息补拉一致 |
| 卡片提交 | 选择 → 确认 | 状态已提交；智能体回执 |
| 右栏三组 | 默认 → 展开 → 收回 | 3/3/3 → 全部 → 3/3/3；顺序符合 |
| 时间轴 | 点击/↑↓/Enter/hover | 定位、高亮、浮层显示 |
| 空/错误态 | 无会话/接口失败 | 空态有动作；错误有原因与重试 |

## 5. 证据格式

- 截图路径；
- 命令 + 输出摘要；
- DOM 测量值（宽度/位置/scrollWidth）；
- 失败时：复现步骤、实际 vs 期望、影响范围。

## 6. 停止条件

- 连续两轮只剩像素级差异（1–2px、色值微调）→ 停止迭代，列 TODO 交付；
- 任一 MUST 需求未通过 → 不上线。
