# FE-001 · 前端整体重构（Spec）

- 状态：`draft`（待评审）
- Owner：产品 `design-scribe` / 前端 `memory-researcher` / 验收 `schema-drafter`
- 来源需求：P9 前端交互、DESIGN.md v2、已冻结的静态原型
- 关联：`frontend/prototype/`、`frontend/review/`、`docs/tasks/frontend.md`

## 1. 背景

旧前端已删除；静态原型已完成并冻结（A-01–A-08 通过）。本 spec 定义把原型落成 React 生产前端，只覆盖「对话」与「工作台」，不恢复任务/智能体/团队/记忆。

## 2. 目标

- 用 React 19 + TS + Tailwind 4 重建可维护前端；
- 视觉与冻结原型一致；
- 对话页接真实 API，发送/流式/卡片/会话动作可用；
- 1600/1180/375 验收通过后才上线 8787。

## 3. 非目标

- 不实现任务/智能体/团队/记忆页面与导航；
- 不实现迁移/拆分/kickoff 新后端能力；
- 不做主题切换/移动端完整功能（375 仅保证可用）；
- 不修改后端领域语义。

## 4. 需求（MUST / SHOULD）

| ID | 级别 | 需求 |
|---|---|---|
| R1 | MUST | 只保留顶层「对话 / 工作台」导航 |
| R2 | MUST | 侧栏：品牌、工作区、搜索、会话树、用量摘要、用户；240 宽、全高 |
| R3 | MUST | 顶栏：面包屑固定 90、白色 segmented 切换、连接状态、设置 |
| R4 | MUST | 对话页：白色全宽头部 + 对话标签；标签下 12px + 1px 分隔线 |
| R5 | MUST | 时间轴：44 gutter、20×4、gap2、垂直居中、当前/hover 24；点击/键盘定位；浅色两栏浮层 |
| R6 | MUST | 消息列：内容基线 494/326；用户/智能体两角色；Markdown；流式/失败态 |
| R7 | MUST | Composer：与内容基线对齐；空/有内容/发送中/错误 |
| R8 | MUST | 右栏：目标→输入→执行会话→交付物；三组默认 3 条、可展开/收回；交付物正常流 |
| R9 | MUST | 交互卡片：表单/按钮；提交走卡片动作；无动作时兜底确认 |
| R10 | MUST | 会话动作：双击行内重命名（Enter 保存/Esc 取消/失焦保存）；不显示置顶/归档按钮 |
| R11 | MUST | 流式：WS subscribe；只消费 reply.delta；断线重连 + 补拉；无重复文本 |
| R12 | MUST | 数据真实：会话/消息/统计来自 API；不造假数据 |
| R13 | MUST | 设计系统：tokens + 固定组件；页面零内联样式；尺寸 2/4/8/16/20/24/32 |
| R14 | MUST | 响应式：1600/1180/375 无横向滚动/裁切/重叠 |
| R15 | SHOULD | 组件画廊同步为 React 版，左导航 + 右滚动 + scrollspy |
| R16 | MUST | 未通过 tsc/build/截图/交互验收前，不部署 8787 |
| R17 | MUST | 页面只组合已登记组件与布局原语；禁止页面定制 CSS/内联样式/一次性视觉类；新需求先扩组件 variant 并登记画廊 |
| R18 | MUST | 组件只暴露受控 variant/size/tone/density，不接受页面 style/className 覆盖；容器（Panel/Section/Divider/List）与业务项（TaskItem/DeliverableItem）必须是独立组件 |
| R19 | MUST | 页面零裸展示元素：所有可见元素来自已登记组件；裸 HTML 仅限无视觉布局包装；新 prop/variant 必须通用化并登记画廊；例外需评审 |
| R20 | MUST | 全站单一组件库：`src/components` + 单一 tokens；页面只能 import 组件；禁止页面内组件/重复 components.css/第二套样式 |

## 5. 验收（Given / When / Then）

| ID | 场景 | 验收 |
|---|---|---|
| A1 | 打开 8787 | 3 秒内看清当前会话与输入区；对话/工作台可切换 |
| A2 | 切换会话 | 消息即时加载，滚动到底；无旧消息残留 |
| A3 | 发送消息 | 出现用户消息；流式回复；结束后不重复、不丢失 |
| A4 | 断网/重启服务 | 状态变“重连中”，恢复后自动补拉，消息一致 |
| A5 | 双击会话 | 进入行内编辑；Enter 保存、Esc 取消、失焦保存 |
| A6 | 卡片 | 下拉 + 确认按钮；提交后状态变已提交；有回执 |
| A7 | 右栏 | 三组默认 3；展开全部/收回；交付物紧随其后可见 |
| A8 | 时间轴 | 20×4/gap2；点击定位；上下键可用；浮层浅色两栏 |
| A9 | 1600/1180/375 | 无横向滚动、无裁切、无重叠 |
| A10 | 视觉 | 与冻结原型一致；不出现内联样式/临时颜色 |
| A11 | 工程 | tsc 0、build 通过、无 console error |
| A12 | 组件画廊 | 左导航/右滚动/scrollspy；组件登记完整 |

## 6. 约束

- 唯一视觉来源：`DESIGN.md` + 冻结原型；
- 不删「对话」功能；
- 失败不静默；不虚构完成；
- 遵循 `AGENTS.md` 六维基线。
