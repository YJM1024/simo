# FE-007 · 祖先消息按会话整级加载（Spec）

状态：**spec ready（待 Lead/前端确认；未实现）**
Owner：前端（实现）/ 产品（本 spec）/ 验收（滚动与时间轴走查）
依赖：会话树/Session API、`TimelineGroups`（COMP-timeline-groups）、现有消息列表。
只写文档，不改代码。

---

## 1. 目标

在对话页默认只显示当前会话；用户可用**顶部按钮**按“直接上级会话”为单位，**整级加载**该上级会话的全部消息；可逐级向上直到根。加载后：

- 时间轴覆盖**全部已加载消息**（祖先 + 当前）；
- 上级会话组 opacity .55、组间 gap6；
- 前置插入消息时**滚动位置不跳**，滚动条范围/容器高度稳定；
- 切换会话**重置**祖先链。

## 2. 非目标

- 不做祖先消息分页、不做“加载更早”按钮、不做按条数懒加载；
- 不把祖先消息合并/复制到当前会话；不改变消息归属；
- 不做跨分支/任意会话跳转加载（只沿 parentId 逐级向上）；
- 不改 Composer、任务/右栏、普通消息发送与流式语义。

## 3. 术语

- **当前会话**：`session:active` 对应的会话；
- **祖先链**：从根到当前会话的 parent 序列（不含当前）；
- **整级加载**：一次请求返回直接上级会话的**全部消息**（无分页/无 cursor）；成功后一次性 prepend；
- **已加载消息**：当前会话已加载的消息 + 已加载祖先的全部消息；时间轴只覆盖这个集合，不承诺覆盖未加载的当前会话旧消息。

## 4. 交互

### 4.1 默认

- 进入/切到会话：只显示当前会话已加载消息；祖先链为空；
- 顶部操作区显示按钮：`加载上级会话：<标题>`；
- 当前会话已是根（无 parentId）：按钮隐藏或禁用，提示“已是根会话”；
- 不自动加载祖先，不在后台预取。

### 4.2 点击加载

1. 读取当前会话的 `parentId`/标题；无 parent → 不显示按钮；
2. 按钮进入 loading（`aria-busy=true`，禁用防重复）；
3. **一次请求**直接上级的全部消息（无分页、无 `before`）；
4. 成功：把整组祖先消息 prepend 到消息列表顶部；时间轴增加对应会话组；按钮更新为“下一级上级”（若还有 parent），到根后禁用/隐藏；
5. 失败：不插入任何消息；保留当前滚动位置；按钮恢复可点，显示错误/重试；
6. 重复点击：已有该祖先 → 不重复插入；可更新按钮指向上一个未加载 parent。

### 4.3 逐级向上

- 每次点击只加载**直接上级整级**，不一次加载全部祖先；
- 加载后可继续点按钮向上；
- 加载到根后按钮禁用/隐藏；根组正常显示，但 opacity 仍按“祖先”规则（相对于当前会话）；
- 祖先链只追加，不重排当前消息；祖先组顺序 root → … → parent → current。

### 4.4 切换会话

- 切换会话（含通过时间轴/树/搜索跳转）重置祖先链：清空所有祖先消息，回到“只显示当前会话”；
- 不把上一个会话的祖先链带到新会话；
- 重新打开同一会话也从默认态开始（除非未来另立缓存 spec；本版不缓存跨切换）。

## 5. 数据/接口需求

> 前端只消费接口；若后端接口未就绪，本 spec 视为“待接口确认”，不得用假数据冒充。

### 5.1 会话 parent

现有会话详情需提供：

```ts
interface SessionMeta {
  id: string
  title: string
  parentId: string | null
  archived?: boolean
}
```

- `parentId` 用于识别直接上级；无 parent / 不可见 → 按钮不出现；
- 不在前端自行从标题/树顺序猜 parent。

### 5.2 祖先整级消息

建议接口（可复用现有 messages 路由，后端确认命名）：

```http
GET /api/sessions/{sessionId}/messages?scope=all
```

响应：

```json
{
  "sessionId": "s-parent",
  "messages": [
    {"id":"m1","sessionId":"s-parent","role":"user","at":1760000000000,"text":"...","category":"clarification"},
    {"id":"m2","sessionId":"s-parent","role":"agent","at":1760000000001,"text":"...","category":"progress"}
  ],
  "hasMore": false
}
```

- `scope=all`：返回该会话全部消息，按时间升序；**不得分页**；不返回 `hasMore=true`；
- 消息字段满足 `TimelineGroups` 所需：`id/sessionId/sessionTitle/category/at/role`；
- 不返回 system/合成消息；不跨会话混入；
- 权限：仅当前用户可见的会话；归档只读仍可读；403/404 明确，不泄露；
- 若后端暂不支持 `scope=all`，可在前端 spec 中降级为“暂不可用”，不得用当前分页接口拼假“全部”。

## 6. 消息与滚动

### 6.1 插入

- 祖先消息整组 prepend 到当前消息列表顶部；祖先组内部按 `at` 升序；
- 不复制/改写当前消息，不改变消息 `sessionId`；
- 同 id 去重；重复加载只保留一份；
- 插入必须在前端一次状态更新内完成，避免中间渲染闪烁。

### 6.2 滚动锚定（硬要求）

前置插入后，用户当前看到的内容**不得跳动**：

1. 加载前记录：`scrollTop`、`scrollHeight`、顶部可见消息 id/偏移；
2. 加载完成后（DOM 更新后同一帧/下一帧）：
   - `newScrollTop = oldScrollTop + (newScrollHeight - oldScrollHeight)`；
   - 若顶部可见消息 id 仍存在，优先以该消息偏移校正；
   - 误差 ≤1px（允许亚像素/浏览器取整）；
3. 加载期间/加载后，滚动容器高度与可滚动范围不因 loading/空态切换而缩小；
4. 不把用户强制拉到底部；不改变当前选中/焦点消息；
5. 滚动条 thumb 位置因内容变长可变化，但**容器/轨道范围稳定**，不出现回弹/闪缩。

### 6.3 时间轴

- 时间轴覆盖全部已加载消息（祖先 + 当前）；
- 会话组顺序 root → … → current；祖先组 opacity **.55**，当前组正常；
- 每切换一级会话组 gap **6px**；44px rail 内无文字；
- 滚动时时间轴与 tooltip 保持，不因 prepend 丢失 active/焦点；
- active 消息仍在当前会话时保持 active；祖先消息可点击跳转，跳转不切换当前会话（由现有跳转规则处理）。

## 7. 状态/错误

| 状态 | 表现 |
|---|---|
| 默认 | 仅当前会话；按钮“加载上级会话” |
| loading | 按钮 spinner/禁用；消息列表不收缩；不显示假消息 |
| error | 按钮恢复；错误文案/重试；不插入部分数据 |
| root | 按钮禁用/隐藏；提示“已是根会话” |
| no-parent | 同 root，不显示不存在的上级 |
| empty-parent | 上级会话存在但 0 条消息：不插入；提示“上级没有消息”，按钮仍可继续向上（若还有 parent） |
| archived-parent | 只读；可加载查看；不显示写操作 |

- 并发：加载中不允许再次触发；同一 parent 的重复请求合并；
- 部分失败：整组成功才插入，禁止半组插入。

## 8. 可访问性

- 按钮可 Tab/Enter/Space；`aria-busy`/`aria-disabled`；名称含上级标题；
- 加载完成用 live region 简短播报“已加载 N 条上级消息”（不重复刷屏）；
- 滚动锚定不抢焦点；焦点保持在按钮或原消息；
- 时间轴键盘行为沿用 TimelineGroups（←/→/Home/End/Enter/Tab）；
- 375 下按钮不溢出；文案可换行/省略；不裁切。

## 9. 验收标准 A1–A10

| # | 场景 | 通过标准 |
|---|---|---|
| A1 | 默认进入 | 只显示当前会话；祖先消息 0 条；无自动请求 |
| A2 | 点击加载直接上级 | 一次请求返回直接上级全部消息（无分页）；整组 prepend；无重复 |
| A3 | 逐级到根 | 每点一次只上一级；到根后按钮禁用/隐藏；组顺序 root→…→current |
| A4 | 切换会话 | 祖先链清空；回到只显示当前会话；不串会话 |
| A5 | 时间轴覆盖 | 时间轴包含全部已加载消息；上级 opacity .55；组 gap6；44 rail 无文字 |
| A6 | 滚动不跳 | prepend 后顶部可见内容偏移 ≤1px；焦点/选中不变；不强制滚底 |
| A7 | 滚动条稳定 | 加载期间容器高度/范围不缩小；插入后无回弹/闪缩；无横向滚动 |
| A8 | 错误/空/重复 | 失败不插入、可重试；空上级提示且不插入；重复加载/重复 id 去重；loading 不可重复点 |
| A9 | 权限/纯度 | 仅可见会话；跨会话 403/404；无 system/合成消息；归档只读可读 |
| A10 | 响应式/可访问 | 1600/1180/375 无破版；按钮键盘可达；时间轴 tooltip/键盘不回归；无自定义页面 CSS |

## 10. 影响范围

- **ConversationPanel / ChatPage**：顶部按钮、祖先链状态、prepend/滚动锚定；
- **TimelineGroups**：接入祖先组、opacity .55、gap6、全部已加载消息；不改 44px rail 规则；
- **API**：需要 parentId + `scope=all` 全量消息接口；未就绪时功能降级为“暂不可用”；
- **Composer/右栏/发送流**：不改；
- **不影响**：任务/团队/记忆/视图页。

## 11. 风险与待确认

- **后端接口**：现有 messages 是否支持全量返回需确认；若只能分页，需后端先补契约，前端不得用分页拼“全部”。
- **当前会话旧消息**：A5 只保证“全部已加载”，不保证当前会话未加载的旧消息；若产品要求完整当前会话，需另立“首次全量/分页”spec。
- **滚动锚定**：不同浏览器对 `scrollTop` 取整/滚动锚定策略不同；以消息 id+偏移校正兜底，误差 ≤1px。
- **祖先组视觉**：只对时间轴 opacity .55，消息本身仍要可读；若对比不足，用 tooltip/组标记补偿，不回退为新增颜色。
- **大祖先会话**：整级加载可能很大；本 spec 明确“无分页”是产品选择，需关注渲染性能；如超阈值，另立性能 spec（不在本版偷偷分页）。
