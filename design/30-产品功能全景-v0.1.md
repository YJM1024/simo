# Part A · 产品能力域（135 个）

## 1. 输入与事件（13）

**目标**：接得住所有外部输入，并变成“有归属、有状态、有下文”的事件。

| ID | 功能 | 系统要做到什么 | 用户可感知 |
|---|---|---|---|
| F1.1 | 多源接入 | 消息、邮件、工单、评论、日程、告警、Webhook、第三方事件 | 所有渠道都能收到 |
| F1.2 | 多模态解析 | 文本、语音、图片、文档、表格、网页、截图 | 发图/发文件/发语音也能处理 |
| F1.3 | 归一与去重 | 同一件事合成一个事件，带上下文、实体、优先级 | 不会被问三遍 |
| F1.4 | 分诊与路由 | 判断要不要处理、谁处理、何时处理 | 知道什么事该找谁 |
| F1.5 | 归属与状态 | 负责人、状态、截止、依赖 | 知道每件事到哪了 |
| F1.6 | 处理闭环 | 接单→响应→执行→结果→验收 | 事情有始有终 |
| F1.7 | 异常与升级 | 超时/失败/高风险 → 升级给人或上级 | 卡住了会喊人 |
| F1.8 | 事件视图与检索 | 收件箱、时间线、筛选、搜索、聚合 | 一眼看到所有事 |
| F1.9 ＋ | 情境感知 | 时间、地点、设备、会议、专注状态 | 它知道我现在方不方便 |
| F1.10 ＋ | 意图理解与实体识别 | 识别意图、实体、指代、约束 | 它真听懂了 |
| F1.11 ＋ | 订阅与监听 | 按关键词/实体/来源持续监听 | 相关的事它会盯着 |
| F1.12 ＋ | 事件关系与线程 | 相关事件串成线程/父子/因果 | 前因后果它清楚 |
| F1.13 ＋ | 事件优先级与 SLA | 按影响/紧急/价值排序，定响应时限 | 急事优先，不误事 |

## 2. 自主推进（14）

**目标**：不等指令也能发现该做什么，并自己往前推——始终在授权与预算内。

| ID | 功能 | 系统要做到什么 | 用户可感知 |
|---|---|---|---|
| F2.1 | 目标管理 | 目标、成功标准、优先级、截止、约束 | 说一次目标它一直记着 |
| F2.2 | 主动发起 | 定时、停滞、异常、机会、订阅 → 自己开任务 | 它会自己找活干 |
| F2.3 | 自主执行 | 任务内自己决定下一步 | 不用一步步指挥 |
| F2.4 | 反思与自检 | 复盘：哪里对、哪里错、下次怎么改 | 它会吃一堑长一智 |
| F2.5 | 请示与停手 | 不确定、高风险、缺授权时停下来问 | 该问的时候会问 |
| F2.6 | 自主等级与开关 | 按域设置 L0–L3，随时暂停/恢复/降级 | 能控制它多主动 |
| F2.7 | 注意力与多目标 | 多目标排序、打断、让路、防铺太开 | 知道先做哪件 |
| F2.8 | 机会发现 | 发现未知、缺口、新信息带来的机会 | 提醒我没想到的事 |
| F2.9 | 自主策略配置 | 内驱组合、频率、静默时段、升级规则 | 能调它的性格 |
| F2.10 ＋ | 意图预测 | 用户开口前预测下一步并准备 | 我还没说它就准备了 |
| F2.11 ＋ | 节律与静默 | 工作/休息/专注/深夜的行为差异 | 该安静时不烦我 |
| F2.12 ＋ | 休眠与唤醒 | 长期任务休眠，到点/有事件再醒 | 它能等，不占资源 |
| F2.13 ＋ | 自我校准 | 知道自己有多大把握，低把握时请示 | 它知道自己不确定 |
| F2.14 ＋ | 目标冲突检测 | 多目标冲突时提示并给取舍 | 目标打架时它会说 |

**目标**：把目标变成可执行、可调整、可交付、可验收的结果。

| ID | 功能 | 系统要做到什么 | 用户可感知 |
|---|---|---|---|
| F3.1 | 任务拆解 | 目标→任务→步骤，粒度可执行 | 再大的事也能拆 |
| F3.2 | 计划表达 | 依赖、里程碑、并行/串行、预算、风险 | 看得到它打算怎么做 |
| F3.3 | 工具与行动 | 浏览器、代码、API、文件、第三方系统 | 真能动手，不只给建议 |
| F3.4 | 执行跟踪 | 状态、进度、产物、日志、耗时 | 做到哪随时知道 |
| F3.5 | 重规划 | 阻塞、新信息、失败 → 改计划 | 路不通会换路 |
| F3.6 | 中断与恢复 | 暂停、人接管、继续、崩溃恢复 | 停了还能接着做 |
| F3.7 | 产物与交付 | 文档、表格、PPT、图、代码、邮件、链接 | 能直接拿走用 |
| F3.8 | 验收与证据 | 自检、独立验收、证据链 | 说完成就真完成 |
| F3.9 | 汇报 | 进展、卡点、下一步、结论，分层 | 汇报像人话 |
| F3.10 ＋ | 情境化准备 | 会前/出行/评审前自动备背景 | 开会前材料已备好 |
| F3.11 ＋ | 周期性汇报 | 日/周/月自动总结进展与风险 | 定期有一份能读的汇报 |
| F3.12 ＋ | 创意发散 | 头脑风暴、类比、变体 | 帮我打开思路 |
| F3.13 ＋ | 推演与沙盘 | what-if、pre-mortem、后果模拟 | 动手前先推演 |
| F3.14 ＋ | 方案对比与谈判支持 | 多方案权衡、让步策略、报价 | 给我选项和底线 |
| F3.15 ＋ | 多模态产物 | 视频/音频/3D/原型/仪表盘 | 产物不只是一段文字 |
| F3.16 ＋ | 产物规范与版本 | 品牌/格式/版本/审批 | 产物拿得出手、可追溯 |

## 4. 多智能体协作（18）

**目标**：按需组队，分工、协作、评审、汇总；不是“一群 Agent 聊天”。

| ID | 功能 | 系统要做到什么 | 用户可感知 |

# Part F · 非目标与开放问题

## F.1 非目标

- 不做通用问答/搜索产品；
- 不做纯 workflow/RPA 搭建器；
- 不做无边界自主、不替代人做高风险决策；
- 不把“多 Agent 群聊”当卖点；
- 不做 AGI、不做意识/情感承诺；
- 暂不做跨组织 A2A、插件市场大规模运营。

## F.2 开放问题

1. 产品形态：个人助理 / 团队数字员工 / 平台？
2. 首批用户：设计 / 客服 / 项目管理 / 个人？
3. 多用户与组织（X1）是否本期就做？
4. 自主等级对外承诺到 L2 还是 L3？
5. 交付与计费：本地/云、席位/按任务/按结果？
6. “像真人”的边界：哪些动作必须人批？
